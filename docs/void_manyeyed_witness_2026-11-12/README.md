- 새 사용자 레퍼런스의 청록색 다면체, 다수의 흰 눈과 붉은 동공, 크림색 작은 날개, 떠다니는 깃털을 계승했다.
- 전방 큰 눈 하나와 보조 눈 군집으로 주목점을 만들고, 몸체의 삼각 면과 보라색 연결 틈이 읽히게 구성했다. 눈이 몸체와 같은 평면 도안으로 보이지 않도록 크기·겹침을 달리했다.
- 독립 원화에 그림자만 추가하는 방식 대신, 참고 전투 화면의 적 배치 구역을 카메라 기준으로 삼고 바닥 타일·단차·부유 그림자를 함께 생성했다.

## 출력 후 시점·형태 검수
