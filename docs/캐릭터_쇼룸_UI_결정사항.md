# 캐릭터 쇼룸 UI 결정사항

사용자가 직접 작성한 합성 구도를 기준으로 합의한 향후 구현 방향이다. 이번 작업은 시안 작성과 흐름 기록이며 게임 코드 구현은 후속 작업이다.

## 사용자가 지정한 흐름

1. 전투 화면에서 Tab 키를 누르면 왼쪽에 기존 캐릭터 선택창이 나타난다.
2. 기존 선택창의 배경, 스탠딩 캐릭터, 좌우 이동, 캐릭터 카드 목록을 가져와 사용한다.
3. 캐릭터를 선택하면 쇼룸의 스탠딩과 해당 캐릭터의 정보가 바뀐다. 쇼룸에서 선택한 캐릭터는 전투에 배치된 캐릭터를 교체하지 않는다.
4. 쇼룸을 여는 동안 전투 화면은 오른쪽으로 이동하고 딤드 처리된다.
5. 사용자가 빨간 선으로 지정한 중앙 오른쪽 영역에 캐릭터 정보를 표시한다. 정보 패널은 딤드된 전투 화면보다 위에 표시한다.

## 정보와 시각 구성

- 스탠딩과 하단 카드 목록은 사용자의 합성 구도를 기준으로 유지한다.
- 정보 영역에는 이름, 역할, 레벨, 주요 능력치, 고유 스킬, 궁극기, 패시브, 장비를 수용한다. 스킬 설명을 생략하지 않는다.
- 전투 캐릭터 선택 상태와 쇼룸 열람 캐릭터 상태는 별도로 관리해야 한다.
- 기존 보라색 선택창과 공허 전장의 남보라색 분위기에 맞춘다. 정보 패널과 텍스트는 선명하게 표시한다.
- 사용자의 후속 피드백에 따라, 오른쪽 정보 UI는 특히 왼쪽 기존 선택창과 같은 조형을 사용한다. 두꺼운 라벤더 카드 테두리, 둥근 모서리, 모서리 하이라이트, 진보라색 오프셋 그림자, 굵은 흰색 글자와 레벨 배지를 기준으로 한다.
- 정보 카드의 배경과 배치는 왼쪽 보라색 대각선 스테이지와 시각적으로 이어지도록 구성한다. 가는 장식 테두리와 정교하게 빛나는 아이콘을 사용한 첫 정보 패널 시안은 사용자의 스타일 요구를 충족하지 못한 이전안이다.
- 과거의 전투 HUD 전면 재구성 시안보다 사용자가 직접 만든 쇼룸 구도가 우선한다.

## 시안에서 가정한 내용

- 재차 Tab 키를 누르면 쇼룸을 닫고 전투 화면이 원위치로 돌아오는 동작을 제안한다. 사용자가 명시한 열기 동작과 구분해 후속 구현 시 확인한다.
- 그림의 금발 스탠딩과 직업 데이터의 연결은 아직 확정되지 않았다. 정보 패널 시안은 `docs/VoidDefense_기획안.md`의 힐러 스킬·능력치 데이터를 예시로 사용한다. 이름과 수치, 스킬을 해당 스탠딩의 확정 설정으로 취급하지 않는다.
- 쇼룸을 열었을 때 전투 시뮬레이션이 계속 진행되는지, 일시정지하는지는 아직 지정되지 않았다. 딤드 처리만으로 일시정지를 추정하지 않는다.
- 현재 프로젝트의 씬 전환용 Tab 입력과 쇼룸 입력의 충돌 여부는 실제 구현 시 점검한다.

## 참고 자료

- 사용자 구도 원본의 보관본은 `docs/character_showroom/user_layout_reference.png`이다.
- 이 구도를 바탕으로 만든 정보 패널 합성 시안은 `docs/character_showroom/showroom_concept_v1.png`이다. imagegen 내장 도구로 생성했다.
- 왼쪽 선택창의 카드·타이포그래피 스타일을 맞춘 후속 시안은 `docs/character_showroom/showroom_concept_v2.png`이다. imagegen 내장 도구를 사용했고 생성 지시는 같은 폴더의 `showroom_concept_v2_prompt.txt`에 보관했다. 사용자의 최종 승인은 아직 받지 않았다.
- 사용자가 요청한 미니멀 변형은 `docs/character_showroom/showroom_concept_v3_minimal.png`이다. 보라색 대각선 배경과 둥근 스킬 카드는 살리고, 새 정보 영역의 두꺼운 테두리·그림자·제목 배지를 줄였다. 능력치와 패시브는 박스 없이 정렬하고 장비는 작은 빈 슬롯으로 표시한다. imagegen 내장 도구를 사용했고 생성 지시는 같은 폴더의 `showroom_concept_v3_minimal_prompt.txt`에 보관했다. 이 변형도 검토용 시안이다.
- 시안 생성 지시는 사용자 원본의 왼쪽 선택창과 전신 스탠딩을 기준으로 중앙 오른쪽에 남보라색 정보 패널을 합성하고, 뒤쪽 전장을 딤드 상태로 두며, 힐러의 능력치·고유 스킬·궁극기·패시브·장비를 표시하는 것이다. 시안의 Tab 닫기와 직업 연결은 위의 가정 항목을 따른다.
- 기존 선택창 씬은 `scenes/Touch_Game_demo_anim.tscn`이다.
- 관련 스크립트는 `scripts/character_select.gd`, `scripts/standing_character.gd`이다.
