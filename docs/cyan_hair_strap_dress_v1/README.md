## 디자인과 형태

하늘색 긴 생머리와 일자 앞머리, 얼굴 양옆의 긴 머리 가닥, 안쪽 분홍/보라색, 파란 눈과 자신감 있는 미소를 가져왔다. 아이보리 끈 원피스와 두 줄의 검정 허리 스트랩, 버클 초커·상완 밴드, 십자 귀걸이, 커프와 체인 팔찌, 허벅지의 수평 밴드를 단순화했다. 원본에 보이지 않는 발은 검정 앵클부츠로 완성했다.

처음부터 기준 네 장의 인체와 그림체로 구성했다. 선택된 인체 초안에서는 원화 그룹32의 자연스러운 몸통·골반·다리 관계를 구체적인 구성 참고로 사용했으며, 다른 최초 원화 세 장도 함께 입력했다. 이후 얼굴을 원래의 자연스러운 가로/세로 관계를 유지한 새 형태로 그려 머리와 몸의 비중을 맞췄다. 외곽 머리카락의 단면 폭을 얼굴이나 두개부의 폭으로 간주해 납작하게 맞추는 방식은 사용하지 않았다.

얼굴의 타원형 눈과 턱 면, 짧은 목~어깨 연결, 작은 몸통, 체중을 받치는 골반·다리, 두 발 방향에 맞는 부츠, 드레스의 큰 접힘을 최초 원화와 함께 시각 확인했다. 액세서리의 세부 모양은 작은 크기에서도 읽히도록 간결하게 해석했다.

## 수동 비례 검수

기준: `../character_style_reference/proportions/README.md`의 동일한 수직 H 정의. 주 머리 정수리와 턱의 **외곽선**을 표시한다. 긴 머리 아래끝은 머리 높이가 아니다.

| 지점 | 최종 y(px) | 정수리 기준 H |
|---|---:|---:|
| 정수리 | 115 | 0.00 |
| 턱 외곽 | 615 | 1.00 |
| 어깨(추정) | 660 | 1.09 |
| 허리(추정) | 805 | 1.38 |
| 가랑이(추정) | 1060 | 1.89 |
| 무릎(추정) | 1230 | 2.23 |
| 발바닥 | 1492 | **2.75** |

H=500px, `(1492-115)/500 = 2.754H`로 최초 네 장의 관찰 범위 약2.67~2.80H 안이다. 턱의 확대 판독에서 초기 y620보다 실제 외곽선에 가까운 y615로 정정했다. 수치는 사람이 그림을 보고 표시한 근삿값이며, 옷과 포즈에 가려진 관절의 정밀한 해부학 치수는 아니다. 수치 통과만으로 모든 형태가 완전히 같다고 주장하지 않는다.
