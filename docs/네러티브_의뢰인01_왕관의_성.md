# 의뢰인 01 — 「왕관의 성」 (첫 스테이지 · 튜토리얼 겸용)

작성일: 2026-11-06 · 상태: **초안** · 상위 문서: `docs/네러티브_기획서.md` (컨셉 원본: `docs/네러티브_컨셉_아이디에이션.md` 5-1)

> 설계 목표
> 1. **새 아트 최소화:** 현재 원화(보라 하늘의 무너진 석조 유적, 큰 달, 왕관 쓴 공허 군주)와 적 4종, 1차 유물 5종을 그대로 쓰고 '의미'만 새로 입힌다.
> 2. **튜토리얼 겸용:** 방 하나에 배울 것 하나. 유물 성좌판 4칸 → 10칸이 이 스테이지 안에서 다 열린다.
> 3. **가벼운 고민:** 진단명 없음. 누구나 한 번은 겪는 "완벽해야 한다"는 부담.

## 1. 의뢰인

| 항목 | 내용 |
|---|---|
| 이름 | **윤하린** (가칭) · 18세 · 학생회장 |
| 고민 | 1등이 아니면 아무것도 아닌 것 같다. 계획표를 지키지 못하면 잠을 못 잔다. 요즘은 좋아하던 밴드 동아리도 그만둘까 생각 중. |
| 겉모습 | 단정한 교복, 손에 꽉 쥔 다이어리. 웃고 있지만 눈 밑이 어둡다. |
| 의뢰 경위 | 상담소 문 앞에 쪽지만 남겨 두고 간다. "제가 왜 여기 왔는지 잘 모르겠어요. 그냥, 머릿속이 너무 시끄러워요." |
| 필요한 아트 | 반신 초상 1장 (평소/웃는 얼굴 표정 2종), 엔딩 컷 1장 |

## 2. 마음 풍경 — 「왕관의 성」

하린의 마음속은 **한때 웅장했던 성의 폐허**다. 상장·트로피를 쌓아 올려 지은 성인데, 너무 높이 쌓다 보니 무너져 하늘에 떠 버렸다.

| 원화 요소 | 이 의뢰인 안에서의 의미 |
|---|---|
| 공중에 뜬 석조 유적 | 성과로 쌓아 올린 '왕관의 성' |
| 떠다니는 돌 파편 | 다 지키지 못한 계획표 조각 |
| 보라 하늘·큰 달 | 밤새 켜 둔 책상 스탠드 불빛. 이 마음속은 늘 밤이다 |
| 별 깃발 거점 (안전 기지) | 동아리방 구석의 낡은 소파. 하린이 유일하게 아무 생각 없이 기타를 치던 자리 |

---

## 3. 엉킨 생각들 (적 리스킨)

기존 적 데이터(`vd_data.gd`)의 능력치와 행동은 그대로 두고, 이름 옆 **별명**과 등장 말풍선만 붙인다.

| type | 기존 이름 | 이 의뢰인 안의 별명 | 등장 말풍선 (랜덤 1줄) |
|---|---|---|---|
| normal | 공허 잔재 | 「해야 하는데…」 | "아직 안 끝났잖아" · "그거 오늘까지였지?" |
| fast | 공허 파편 | 「조급함」 | "빨리빨리!" · "벌써 늦었어!" |
| skirmisher | 공허 포자 | 「수군거림」 | "회장이 저것도 못 해?" (멀리서 쏘는 = 남의 시선) |
| tank | 공허 결정체 | 「완벽한 계획표」 | "5분 단위로 지켜." (단단하고 느리다) |
| boss | 공허 군주 | **「1등의 왕관」** | 4장 참고 |

- 처치 연출은 기존 그대로 두되, 효과음 자막을 "BANG!" 대신 "정리!", "치웠다!" 등으로 섞는다 (선택).

## 4. 진행 — 방 6개 + 보스

그레이박스 루프(배치 → 전투 → 구역 클리어 → 칸 +1 → 유물 3택1 → 갈림길) 그대로. 첫 전투에 4칸, 방마다 +1칸, 보스 방까지 깨면 10칸이 다 열린다.

| # | 방 (기억) | 배우는 것 | 들어갈 때 대사 | 클리어 보상 기억 (유물) |
|---|---|---|---|---|
| 0 | **성문** (상담소 → 마음 입장) | 영웅 배치 | 반장 "자, 오늘 정리할 집은 여기예요. 신발은 벗고 들어가요." | — (시작 보관함: 뇌운 조각·잉걸불) |
| 1 | **새벽 4시의 책상** | 자동전투·평타 | 마법사 "공책이 여섯 권 펼쳐져 있네요. 다 오늘 거래요." | 뇌운 조각 / 잉걸불 배치 연습 |
| 2 | **게시판 앞 복도** (성적표) | 고유 스킬 | 건너 "1등 옆에 이름이 있는데… 왜 본인은 2등 칸만 보고 있죠?" | 서리 결정 (3택1 처음 등장) |
| 3 | **텅 빈 동아리방** | 궁극기 | 힐러 "여긴 먼지만 쌓였어요. …근데 이 기타는 줄이 새 거예요." | 공허 정수병 |
| — | 갈림길 A/B | 경로 선택 | "어느 기억부터 볼까요?" | — |
| 4A | **축제 무대 뒤** | 유물 배치 문법(인접 보너스) | 기사 "여긴 공기가 다르네. 따뜻해." | 잉걸불 (2번째) |
| 4B | **혼자 남은 교실** | 침식 칸·정화 | 반장 "생각이 바닥에 들러붙었어요. 문질러서 지워요." | 서리 결정 (2번째) |
| 5 | **왕좌의 방 앞 계단** | 보스 전 정비 | 힐러 "위에서 누가 계속 소리치고 있어요." | 별 깃털 (확정) |
| 6 | **왕좌의 방** — 보스 「1등의 왕관」 | 보스 바·위기 대응 | 아래 참고 | 클리어 → 엔딩 |

### 유물 = 하린의 좋은 기억 (플레이버 텍스트)
유물 이름과 기능은 그대로 두고, 이 스테이지에서 얻을 때만 툴팁 아래에 회색으로 '누구의 어떤 기억인지' 한 줄을 붙인다.

| 유물 | 하린의 기억 한 줄 |
|---|---|
| 뇌운 조각 | "축제 기획 회의에서 내 아이디어에 다들 '오!' 했던 순간." |
| 잉걸불 | "첫 합주가 끝났을 때 손끝에 남아 있던 찌릿한 열기." |
| 서리 결정 | "시험 끝난 날, 친구랑 눈 맞으면서 먹은 아이스크림." |
| 공허 정수병 | "동아리 애들이 몰래 써 준 롤링페이퍼. '회장 고마워'." |
| 별 깃털 | "초등학생 때 꼴찌로 들어온 운동회 날, 아빠가 '끝까지 뛰었네' 해 준 말." (위기 때 지켜 주는 기억) |

- 별 깃털이 '위기 시 보호막'이라는 게 서사와 딱 맞는다. 보스 방 직전에 확정 지급해 보스전에서 한 번은 발동하게 한다 (6-3의 "임계치형 0회 발동" 문제도 같이 해결).

### 침식 = "부족해" 얼룩
- 4B 방과 보스 방 클리어 때 생기는 침식 칸 위에 작은 글씨로 "부족해", "더 해야 해"를 띄운다. 정화하면 글씨가 지워지며 칸이 돌아온다.

## 5. 보스 — 「1등의 왕관」

- **외형:** 기존 공허 군주 그대로. 왕관이 이 의뢰인 안에서는 금빛 종이 왕관으로 보이게 하면 더 좋다 (선택, 셰이더 색만 바꿔도 됨).
- **등장 컷인:** 이름 「1등의 왕관」 · 별명 "2등은 꼴찌랑 똑같아"
- **전투 중 외침** (기믹 메시지 자리, HP 75/50/25%에 1줄씩):
  1. "아직 부족해!"
  2. "쉬면 다 따라잡혀!"
  3. "…날 벗으면, 넌 아무것도 아니잖아."
- **처치 → 진정:** 쓰러지면 터지지 않고 줄어들어 **유치원 때 만든 종이 왕관**이 된다 (E의 화해 구조).
  - 반장 "이거, 처음 1등 했을 때 받은 거래요. 그때는 그냥… 기뻤대요."
- **마지막 문은 의뢰인이 연다:** 분대가 왕좌의 방 뒤 작은 문 앞에서 멈춘다. 하린의 초상이 처음 등장한다.
  - 하린 "…이 문은 제가 열어도 돼요?"
  - 힐러 "그럼요. 여긴 하린 씨 집인걸요."

---

## 6. 엔딩 (컷 3장)

1. 문 너머: 낡은 소파와 기타가 있는 동아리방. 하린이 종이 왕관을 소파 위에 살며시 내려놓는다.
2. 현실: 아침, 책상. 계획표 맨 아래에 연필로 한 줄을 덧쓴다. 「토요일 — 합주」
3. 휴대폰 메시지: "이번 주에 떡볶이 먹을래? 할 얘기 있어." → 친구 답장 "ㅇㅋㅋ 드디어!!"

- 상담소 마무리: 반장 "다 치운 건 아니에요. 그래도 이제 걸려 넘어지진 않을 거예요."
- 보상 화면: 「의뢰 완료 — 윤하린」 + 하린 엽서 1장 (상담소 벽 수집품. 의뢰인마다 1장씩 쌓이는 메타 수집).

### 분대 전멸 시
- 컷인 1장: 상담소 소파에 늘어진 분대. 반장 "오늘 상담은 여기까지! 하린 씨, 다음 주에 또 봬요."
- 영구 성장(시간의 결정)은 유지. 하린의 다음 회차 첫 대사가 바뀐다: "…또 와 주셨네요." (재도전이 관계 진전으로 느껴지게)

## 7. 분대 대사 담당 (이름 미정이라 역할로 표기)

| 역할 | 이 스테이지에서의 말투 |
|---|---|
| **반장** (멜빵 작업복 소녀, char_02) | 상담소 현장 반장. 일 얘기하듯 툭툭, 그런데 핵심은 정확히 짚음 |
| 기사 | 직설적이고 따뜻함. 감탄 담당 |
| 건너 | 눈치 빠른 관찰자. 숫자·디테일에서 숨은 사실을 찾음 |
| 마법사 (보라 메이드) | 조용하고 건조한 유머 |
| 힐러 (금발 메이드) | 다정함. 의뢰인에게 직접 말을 거는 역할 |

- 반장은 전투 분대가 아니라 좌하단 턴테이블 자리의 **해설자**로 쓴다 (현재 HUD 목업의 좌하단 캐릭터 자리와 맞음).

## 9. 열어둔 것
1. 하린의 이름·나이 확정 (학생이 아닌 사회초년생 버전도 가능: 「신입 사원의 왕관」)
2. 상담소 세계 쪽 설정: 분대가 어떻게 마음에 들어가는지 (꿈 열쇠, 상담소 소파의 마법 등). 첫 의뢰에서는 설명 없이 "신발 벗고 들어가요" 한 줄로 넘기는 안을 추천
3. 효과음 자막을 "BANG!"에서 "정리!" 계열로 바꿀지
4. 의뢰인 엽서 수집을 메타 진행(도감)으로 쓸지
