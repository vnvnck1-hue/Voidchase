## 원화 유지 범위

- 원화에서 보이는 그림은 네이티브 해상도로 잘라냈습니다. 발판과 프랍 뒤에 가려진 영역, 인물의 목과 무기 손잡이 접합부, 프레임에 잘린 돌 끝은 주변의 원본 픽셀을 샘플링하고 기존 윤곽과 타일 줄을 연장해 보완했습니다. 가려졌던 영역의 정확한 모양은 단일 PNG에서 알 수 없어 이 부분은 근사 복원입니다.
- 원경 1장은 화면 전체를 채우며 나머지 PNG 63장은 투명 여백을 포함합니다. 배경의 `reference_edge_matte`, 캐릭터 효과 폴더의 `tile_tint_*` 4장과 `ambient_cast_light`는 원래 합성에 포함된 혼합 가장자리, 발밑 그림자와 색 번짐을 재현하는 보조 레이어입니다. 이 6장을 포함해 원래 순서와 위치에 합성한 PNG를 원화와 비교했습니다.
- 기준 캔버스는 1672×941입니다. 웨이브와 마나 수치는 원화와 동일한 고정 이미지입니다. 보스 체력바는 원화의 빈 트랙과 현재 상태의 채움을 각각 담습니다.

## Godot에서 사용

### 원화 배치 재현

1. 원화 크기인 1672×941 캔버스에서 시작합니다. 프로젝트의 기본 뷰포트는 1920×1080이므로, 원화 크기로 확인할 때는 1672×941 `SubViewport`를 사용합니다. 게임 화면에 맞출 때는 전체 캔버스를 한 번에 비율을 유지하며 확대합니다.
2. `assembly.json`의 `layers` 순서대로 같은 `Node2D` 아래에 `Sprite2D`를 추가합니다. 순서는 뒤에서 앞으로입니다. 각 스프라이트의 `centered`를 끄고, `offset = Vector2.ZERO`, `position = Vector2(position_px[0], position_px[1])`, `scale = Vector2.ONE`을 사용합니다. 음수 좌표도 그대로 둡니다.
3. 정지 화면을 원화처럼 합칠 때는 `reference_only` 레이어 6장도 포함합니다. 각 레이어의 투명 영역을 포함한 PNG 전체를 사용합니다.

### 캐릭터 애니메이션 조립

- 영웅 루트의 `position`에 `rigs`의 `root_px`를 넣습니다. 각 파츠는 `Sprite2D.centered = false`, `offset = -Vector2(pivot_px[0], pivot_px[1])`, `position = Vector2(offset_from_root_px[0], offset_from_root_px[1])`로 두고, 해당 파츠의 `z_index`를 적용합니다. 파츠별 설정은 위의 전체 화면 조립 설정을 대신합니다. 전체 크기를 바꿀 때는 영웅 루트를 스케일링합니다.
- 프랍 피벗은 중심 부근, 몬스터 피벗은 바닥에 닿는 부분에 뒀습니다. 애니메이션에는 해당 스프라이트를 사용하고, `reference_only`는 원화의 정지 화면을 합칠 때 사용합니다.

픽셀 차이 0개는 PNG 파일과 `assembly.json` 좌표를 사용한 1672×941 재합성 결과입니다. Godot 화면은 창 크기, 필터링과 렌더러의 알파 처리에 따라 픽셀 값이 달라질 수 있습니다.
