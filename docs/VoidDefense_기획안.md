## 1. 데모 게임 해부 (무엇을 유지할지 정하기 위한 정리)

### 1-1. 핵심 루프 (phase 상태 기준)

```
placement ──[전투 시작]──> spawning ──> battle ──(적 전멸)──> transition ──> placement(다음 웨이브)
    ▲                                   │                        │
    │                                   └─(영웅 전멸)─> gameover   ├─ 매 3웨이브: 특성(Perk) 3택1 (리롤 500G+500씩)
    │                                                            ├─ 매 10웨이브: 상점 (리롤 300G, 부활 가능)
    └────────────────────────────────────────────────────────────┘  └─ 20웨이브↑ 2차, 25웨이브↑ 3차 서브웨이브
```

| 단계 | 데모 동작 |
|---|---|
| placement | 영웅 3명을 하단 안전구역에 드래그 배치. 스킬 포인트 분배, 아이템 장착/판매/합성, 특성 트리 열람. 자동 시작 토글. |
| spawning | 적이 상단 2줄에 170ms 간격으로 순차 등장 (spawnBurst 연출). 기믹 메시지 표시. |
| battle | 완전 자동: 이동·평타·마나 충전 → 고유 스킬 자동 발동. 영웅 롱프레스 → 슬로모션 **궁극기 조준 모드**. 골드 드랍 수집, 아이템 드랍, 경험치/레벨업. |
| transition | 영웅이 시작 위치로 복귀, +50 회복(특성 보너스), 시간의 결정 +2, 골드 일괄 회수. |
| gameover | 영웅 전원 사망. 재시작 시 영구 특성 트리·시간의 결정·영구 유물은 유지. |

### 1-3. 데모에서 버릴 것

- 세로형 레이아웃(모바일 세로 비율 가정) → 원화는 **가로 16:9**.
- 이모지 아이콘 전부 → 전용 아이콘 세트.
- 사이드 패널에 상시 노출되던 인벤토리/스킬 패널 → **하단 분대 바 + 모달 오버레이**로 정리.
- 밝은 초록·주황 그라데이션 타일 배경 → 공허 유적 팔레트.

## 3. 전환 설계

### 3-1. 세계관 & 네이밍

- 타이틀: **VOID DEFENSE** (부제: 공허 유적의 전술 방어전)
- 배경: 공허에 잠식된 떠다니는 유적. 분대는 유적 좌측 거점(별 깃발)을 지키며 우측 균열에서 쏟아지는 "공허의 잔재"를 막는다.
- 진행 단위: 데모의 wave N을 그대로 쓰되 **5웨이브 = 1스테이지**로 묶어 표시한다.
  - 표시: `스테이지 3 · WAVE 2/5` (내부 wave = 12)
  - 스테이지 마지막 웨이브(5의 배수)는 **보스 웨이브** → 상단 보스 바 표시
  - 데모의 "매 3웨이브 특성 / 매 10웨이브 상점" 주기는 그대로 유지 (상점 = 짝수 스테이지 클리어 직후)
- 재화
  - **공허 정수** (보라 불꽃): 데모의 골드. 드랍·수집·상점·리롤에 사용.
  - **시간의 결정** (파란 결정): 데모 그대로. 영구 특성 트리용.
- 데모의 40웨이브 보상(커피)은 **"공허 군주 토벌" 엔딩 컷인 + 무한 모드 해금**으로 교체.

### 3-2. 전장 (보드)

| 항목 | 값 |
|---|---|
| 논리 그리드 | **10열 × 6행** (x: 0~9, y: 0~5) |
| 아군 배치 구역 | x 0~3 (좌측 4열), 깃발은 x = -1 위치 장식 |
| 적 스폰 구역 | x 8~9 (우측 2열, 데모의 "상단 2줄"과 동일 역할) |
| 거리 계산 | 데모의 맨해튼 거리 그대로 (아이소는 렌더만 바뀜) |
| 타일 크기 | 아이소 128×64 px (1920×1080 기준), 보드 전체 약 1280×640 |
| 보드 위치 | 화면 중앙 살짝 우측, 좌상단 HUD와 겹치지 않게 |
| 정렬 | `y_sort` 활성, 유닛 z = 발 위치 기준 |
| 셀 하이라이트 | 아군 셀 하늘색 네온, 적 셀 붉은 네온, 배치 가능 영역은 placement 중 옅은 하늘색 격자 |
| 2×2 적 | giant 계열은 데모처럼 2×2 점유 유지 (아이소에서 자연스럽게 큼) |

**좌표 변환**: 데모 코드의 `(x, y)`를 그대로 쓰고 렌더 시에만
`screen_x = (x - y) * 64 + origin_x`, `screen_y = (x + y) * 32 + origin_y`.
이동 방향 4방향(상하좌우)도 유지 — 아이소에서는 대각선으로 보이지만 플레이 감각은 동일.

### 3-3. 분대 (영웅 4인)

데모의 UNIT_TYPES 수치를 출발점으로 쓰고, 힐러만 신규.

| 슬롯 | 원화 캐릭터 | 데모 대응 | 역할 | 사거리 | 기본 스탯 (데모 기준) | 고유 스킬(마나 100) | 궁극기(롱프레스) |
|---|---|---|---|---|---|---|---|
| 1 | 핑크 트윈테일 **건너** (SMG) | ranger | 원거리 지속 딜 | 3 | HP120 / ATK40 | 다중 사격 (후퇴 후 3명 사격) | 집중 포화 (부채꼴 2초) |
| 2 | 퍼플 메이드 **마법사** (오브) | mage | 광역·빙결 제어 | 3 | HP100 / ATK55 | 절대 영도 (전체 1초 빙결) | 체인 라이트닝 → **공허 전류**(보라) |
| 3 | 블론드 **기사** (검+방패) | warrior | 전열 탱커 | 1 | HP200 / ATK30 | 용맹한 강습 (점프 착지) | 충격파 (넉백+기절) |
| 4 | 블론드 메이드 **힐러** (십자 지팡이) | 신규 | 회복·지원 | 2 | HP110 / ATK20 | **성역**: 주변 3×3 아군 HP 25% 회복 + 2초 피해감소 | **부활의 빛**: 범위 지정, 범위 내 사망 영웅 1명 HP 40% 부활 + 아군 전원 회복 |
| 5~6 | 잠금 | — | 확장 로스터 | — | 시간의 결정 또는 스테이지 클리어로 해금 | — | — |

힐러 패시브 스킬 3종 (SP로 레벨업, 스킬북 교체 가능):

| id | 이름 | 효과/레벨 |
|---|---|---|
| mend | 응급 처치 | 평타가 가장 체력 낮은 아군을 ATK×0.6 회복(공격 대신) 확률 +20% |
| aura | 수호 결계 | 힐러 주변 1칸 아군 받는 피해 -6% |
| grace | 은총 | 아군이 적 처치 시 힐러 마나 +8 |

힐러 스킬북 3종: `holyBurst`(회복 시 주변 적 피해), `martyr`(사망 시 아군 전원 회복), `tempo`(아군 공속 +4%/Lv).

**영구 특성 트리**: `healer` 분기 8노드 추가 (회복량 / 마나 / 결계 범위 / 최종: "두 번째 기회" 강화).

### 3-6. 신규 소규모 규칙 (원화에서 유도, 전부 선택적)

1. **거점(깃발) 피해**: 적이 x=0 열에 도달해 3초 머무르면 거점 HP -1 (최대 3). 거점 HP 0 = 게임오버. 데모엔 없지만 "방어전" 명분을 준다. 토글 가능하게 구현.
2. **작전 목표** (균열 원화): 스테이지마다 부가 목표 2개 (예: 아군 전원 생존, 90초 내 클리어, 궁극기 3회 사용). 달성 시 시간의 결정 +1씩. 데모의 결정 획득 루트를 넓혀 메타 진행 속도를 조절.
3. **배속·일시정지** (왕관체 원화): ×1 / ×2, 일시정지. 데모의 autoStartBattle 토글과 함께 우상단 묶음.

## 7. 열어둔 결정 사항

1. **거점 피해 규칙** 도입 여부 (3-6-1). 넣으면 "방어전" 명분이 생기지만 데모 밸런스가 바뀐다. 기본값은 OFF로 구현해 두고 플레이 후 결정.
2. **잠금 슬롯 2개의 해금 캐릭터**: 기존 선택창 8인(`char_panels`) 중 누구를 쓸지, 역할(서브 딜러/서브 탱) 배정.
3. **보드 크기 10×6 vs 12×6**: 확장안 원화는 더 넓다. 10×6으로 시작하고 건너 사거리 3·마법사 3 체감을 본 뒤 조정.
4. **힐러 밸런스**: 데모엔 회복 직업이 없어 웨이브 종료 +50 회복으로 버텼다. 힐러가 들어오면 웨이브 종료 회복량이나 적 공격력을 소폭 상향해야 할 수 있다.
