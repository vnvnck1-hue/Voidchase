# 주황 머리·회색 재킷 캐릭터

최종 선택본: [orange_blazer_selected.png](orange_blazer_selected.png). 1041×1511 RGBA PNG. 내장 image_gen으로 제작했으며 생성된 알파와 픽셀을 보존했다. 게임의 기존 에셋을 교체하지 않았다.

## 참고 구분

- 최상위 화풍·비례: ../character_style_reference/의 최초 기준 원화 네 장 전체.
- 외형·무드: [사용자 원화](references/design_mood.png). 주황빛 긴 머리, 민트 꽃 장식과 머리끈, 회색 재킷과 주름치마, 버건디 리본, 당황한 표정과 양손을 펼친 제스처를 참고했다.
- 잘린 하반신은 어두운 니삭스와 둥근 로퍼로 완성했다.
- 선화는 필압 변화, 가늘어지는 내부선, 미세한 브러시 가장자리 질감을 요청하고 최초 네 장과 비교했다.

## 검수

최초 초안과 중간 수정본은 비례가 충분히 맞지 않아 최종으로 선택하지 않았다. 최초 초안의 머리·얼굴을 소폭 다시 그린 orange_blazer_selected.png 한 장을 납품본으로 선택했다. 기존 그림을 가로·세로로 압축하거나 늘리는 후처리는 하지 않았다.

수동 투영 측정: 주 머리 정수리 y=8, 턱 y=557, H=549px, 발바닥 y=1508. 전신 비례는 (1508−8)/549 ≈ **2.73H**로 최초 네 장의 2.67~2.80H 범위 안이다. 추정 어깨 1.10H, 허리 1.45H, 가랑이 1.96H, 무릎 2.23H. 의상과 포즈에 가려진 관절 위치는 근사치다.

같은 H로 나란히 정렬한 [비교표](proportion_audit/reference_comparison.png)에서 둥근 얼굴, 큰 눈, 짧은 목, 작은 몸통, 단순화한 팔·다리와 손발을 함께 확인했다. 주 머리의 가로 단면은 y≈310에서 x≈158~831, 약 1.23H로 기존 단면 추정 범위 약 1.26~1.48H보다 약간 좁다. 옆으로 쓸린 머리의 외곽 단면이며 두개부 폭을 뜻하지 않는다. 수치에 맞추기 위해 얼굴이나 전신을 늘리지 않았다. 소매·치마의 외곽과 실제 어깨·골반 폭도 구분해 비교했다.

투명 PNG 여부는 [알파 검사](alpha_selected.json)로 확인했다. 생성된 PNG의 내부에도 일부 부분 투명이 있으므로 완전 불투명 픽셀만으로 이루어진 에셋이라고 주장하지 않는다. 비교표의 흰 배경 합성에서 배경 장면이나 번지는 광륜 없이 형태가 읽히는 것을 확인했다.
