# FTUE 분석 및 게임 구조 설계

작성일: 2026-11-13 · 브랜치: `ftue-flow` (워크트리 `.claude/worktrees/ftue-flow`)
상위 문서: `docs/네러티브_기획서.md` · `docs/네러티브_의뢰인01_왕관의_성.md` · `docs/첫세션_코어사이클_시나리오.md`

> 목표: 유저가 exe 를 처음 켠 순간부터 **전투 한 사이클(의뢰 1회)을 마치고 허브로 돌아올 때까지** 끊기지 않고 몰입하게 한다.
> 지금까지는 코어 사이클(방 전투)만 깊게 다듬어져 있었고, 그 앞뒤를 감싸는 "게임의 뼈대"가 비어 있었다.

## 1. 진단 — 지금 빌드에 없던 것

처음 켠 유저의 눈으로 exe 를 따라가며 적었다. (작업 전 기준)

| # | 구간 | 지금 상태 | 유저가 느끼는 문제 | 심각도 |
|---|---|---|---|---|
| 1 | 첫 화면 | "PROTOTYPE LOBBY" + 모드 6개 목록 (전투·연구실·쇼룸이 같은 무게) | 무엇이 '게임'인지 모른다. 개발 도구가 먼저 보인다 | ★★★ |
| 2 | 동기 | 세계·의뢰인·분대 소개 없음 | 왜 싸우는지, 누구를 돕는지 모른 채 전투 시작 | ★★★ |
| 3 | 온보딩 | 안내 띠 한 줄뿐. 배치·자동전투·궁극기·유물·갈림길·패링을 한꺼번에 스스로 알아내야 함 | 궁극기 카드를 한 번도 안 누르고 끝날 수 있다 | ★★★ |
| 4 | 런의 끝 | 끝이 없는 절차 생성. 이기는 상태가 없다 | "언제 끝나지?" 목표·성취 지점이 없다 | ★★★ |
| 5 | 결과 | 패배 패널 = 도달 WAVE + 다시 도전 | 내가 뭘 했고 뭘 얻었는지 정리되지 않는다 | ★★☆ |
| 6 | 메타 진행 | 세이브 없음. 매번 처음부터 | 다시 켤 이유·다시 도전할 이유가 없다 | ★★★ |
| 7 | 실패의 무게 | "거점 함락" + 흑백 | 가벼운 톤과 어긋나고, 실패가 손해로만 느껴진다 | ★★☆ |
| 8 | 전투 중 이야기 | 대사 0줄 | 캐릭터가 '유닛'으로만 보인다. 방과 방이 구분되지 않는다 | ★★☆ |
| 9 | 이탈 방지 | Esc 한 번에 확인 없이 로비로 (런 증발) | 실수로 진행을 잃는다 | ★★☆ |
| 10 | 로딩 | "NOW LOADING" 만 | 기다리는 시간이 정보 없이 흐른다 (팁·맥락 없음) | ★☆☆ |
| 11 | 다음 목표 | 없음 | 한 판 끝나면 할 일이 없다 | ★★☆ |
| 12 | 소리 | 효과음만, BGM 없음 | 허브·전투의 분위기 차이가 약하다 | ★☆☆ (이번 범위 밖) |

요약하면 **"첫 30초의 약속 → 목표가 있는 한 판 → 정리와 보상 → 다시 할 이유"** 라는 바깥 고리 전체가 비어 있었다.

## 2. 설계 원칙 (최근 인디 로그라이트에서 가져온 것)

1. **바로 손에 쥐여 준다** — 타이틀에서 첫 전투까지 1분 안. 프롤로그는 탭으로 넘기고 길게 누르면 통째로 건너뛴다. (Hades · Vampire Survivors 계열: 설명보다 플레이가 먼저)
2. **허브가 메뉴다** — 버튼 목록 대신 '공간'. 상담소 모니터룸 그림 위에 의뢰 카드와 반장이 서 있고, 메뉴는 그 공간의 일부다. (Hades 의 집, Slay the Spire 2·Balatro 의 한 화면 허브)
3. **한 번에 하나만 가르친다** — 튜토리얼 전용 스테이지 없이, 실제 첫 런 위에 상황이 올 때마다 한 줄씩. 한 번 본 안내는 다시 안 뜬다.
4. **실패해도 한 바퀴 돈다** — 져도 결정(메타 재화)을 받고 허브 기능이 열린다. 패배 문구는 "오늘 상담은 여기까지".
5. **런에는 끝이 있다** — 의뢰 1건 = 방 5개 + 보스. 이기면 이야기 보상(엔딩 컷)과 수집품(엽서).
6. **이야기는 끊지 않고 흘린다** — 전투 중 대화창 금지. 방 입장·클리어·보스 체력 구간에 말풍선 한 줄.
7. **개발 도구는 뒤로** — 연구실·쇼룸은 허브의 [연구실] 탭으로 옮긴다 (숫자키 바로가기는 유지).

톤: 2026-11-12 지시(사이파이·사이버틱)를 따라 상담소는 **모니터룸에서 의뢰인의 마음에 '다이브'하는 야간 상담소**로 그린다. 배경은 `로비_모니터룸_2종_v12` 컨셉 원화.

## 3. 새 구조 — 화면 흐름

```
[부팅] 타이틀 ──(첫 실행)──▶ 프롤로그: 접수된 쪽지 → 반장 → 분대 한 마디씩
   │                                   │
   └──(재방문)──────────────┐          ▼
                            ▼    "신발은 벗고 들어가요"
                     ┌── 상담소 허브 ──┐
                     │ 의뢰 카드 · 분대 · 강화 · 엽서 벽 · 연구실 │
                     └───┬───────▲────┘
                 다이브  │       │ 결과 (완료: 엽서 + 결정 / 중단: 결정)
                         ▼       │
   로딩(접속 문구·팁) ─▶ 의뢰 런: [배치 → 전투 → 클리어 → 기억 조각(유물) → 갈림길 → 이동] × 4 ─▶ 보스 방
                                 │                                               │
                                 └─ 전멸: "오늘 상담은 여기까지" ─▶ 결과         └─ 진정 → 마지막 문 → 기억 로그 3장 ─▶ 결과
```

### 3.1 타이틀 (`scripts/hub/hub_title.gd`)
- 검정 → 부팅 로그 몇 줄 → 달과 로고 **VOID DEFENSE** + 부제 "야간 마음 정리 상담소".
- "아무 키나 눌러 접속". 하단에 소재 안내 한 줄 (기획서 원칙 6).
- 앱을 켠 뒤 한 번만. 전투에서 돌아올 때는 바로 허브.

### 3.2 프롤로그 (첫 실행만, `scripts/story/story_dialog.gd`)
- 접수 화면에 쪽지: "제가 왜 여기 왔는지 잘 모르겠어요. 그냥, 머릿속이 너무 시끄러워요. — 윤하린"
- 반장 → 기사 → 건너 → 마법사 → 힐러 한 마디씩 (기존 스탠딩·컷인 초상 재사용).
- 탭/Space 로 넘김, **길게 누르거나 [건너뛰기]** 로 전부 스킵. 끝나면 곧장 첫 다이브.

### 3.3 상담소 허브 (`scripts/lobby.gd`)
- 배경: 모니터룸 원화 + 스캔선·비네트, 마우스 패럴랙스.
- **의뢰 카드**: 의뢰인·고민 한 줄·마음 풍경·회기 수·최고 도달 방·보상. 큰 버튼 **[다이브 시작]** (Space/Enter).
- **반장**: 왼쪽 아래 스탠딩(idle 시트) + 상황별 말풍선 (첫 방문 / 패배 뒤 / 클리어 뒤).
- 탭: **의뢰 · 분대 · 강화 · 엽서 벽 · 연구실**. 분대·강화·엽서 벽은 첫 의뢰를 다녀오면 "NEW" 와 함께 열린다 (이기든 지든).
- 클리어 뒤: 다음 의뢰 예고 카드(잠김) + **무한 야근(끝없는 모드)** 해금 — 기존 절차 생성 무한 전투를 그대로 살린다.

### 3.4 의뢰 런 (`scripts/meta/case_data.gd` · `scripts/void_defense/vd_case_run.gd`)
- 의뢰 01 「왕관의 성」 = 방 5개. 기존 스테이지 규칙을 그대로 쓴다 (새 밸런스 없음):

| 방 | 이름 (기억) | 기존 규칙 | 배우는 것 |
|---|---|---|---|
| 1 | 성문 | 스테이지 1 (웨이브 2) | 배치 · 자동전투 · **궁극기** (2번째 웨이브에 게이지 보장) |
| 2 | 새벽 4시의 책상 | 스테이지 2 | 기억 조각(유물) 고르기 · 성좌판 |
| 3 | 게시판 앞 복도 | 스테이지 3 (공허 망루) | 강적 · 갈림길 |
| 4 | 텅 빈 동아리방 | 스테이지 4 (공허 망령) | 중보스 |
| 5 | 왕좌의 방 | 스테이지 5 (공허 응시자) | 보스 · 패링 |

- 의뢰 모드에서는 **보스 방을 뺀 모든 방**에서 기억 조각 3택1 (무한 모드는 기존대로 3구역마다).
- 도착하면 좌상단에 장소 카드 「방 이름」, 입장 대사 1줄, 클리어 리액션 1줄, 보스 체력 75/50/25% 외침.
- 적 이름표: 의뢰 안에서는 별명(「해야 하는데…」 등)으로 안내 띠에 소개.
- 보스 방 클리어 = **의뢰 완료**: 배너 → 마지막 문 대화(하린·힐러) → 기억 로그 3장 → 결과.

### 3.5 튜토리얼 코치 (`scripts/void_defense/vd_coach.gd`)
상황이 처음 올 때 한 번만, 화면 아래쪽 안내 카드 + 대상 강조 고리. 전투는 멈추지 않는다.
`배치(드래그)` → `전투 시작` → `자동전투·마나` → `궁극기 준비(카드 강조)` → `정수 회수` → `기억 조각 선택` → `성좌판에 끼우기` → `갈림길` → `패링`.
본 안내는 `user://save.cfg` 에 기록되고, 허브 설정에서 다시 켤 수 있다.

### 3.6 결과 화면 (`scripts/void_defense/vd_result_screen.gd`)
- 완료: **「의뢰 완료 — 윤하린」** / 중단: **「오늘 상담은 여기까지」** (흑백 대신 차분한 남색).
- 정리한 방 · 치운 엉킨 생각 · 되찾은 기억 · 모은 정수 → **시간의 결정 +N** 으로 환산 (숫자가 굴러 올라감).
- 완료 시 엽서 1장 뒤집기. 버튼: **[상담소로]** / [다시 다이브].

### 3.7 메타 고리 (`scripts/meta/game_save.gd`)
- `user://save.cfg`: 첫 실행 여부, 의뢰별 회기·클리어·최고 방, 결정, 강화 단계, 엽서, 본 안내 목록.
- **강화 4종** (결정 소모): 분대 체력 · 방 클리어 회복 · 시작 정수 · 시작 궁극기 게이지. 다음 다이브부터 적용.
- 엽서 벽: 의뢰인마다 1장. 빈 액자가 수집 목표를 보여 준다.

### 3.8 그 밖
- **일시정지 메뉴**: 의뢰 중 Esc → 계속 / 처음부터 / 중단하고 상담소로 (중단도 결정 정산).
- **로딩**: 접속 문구("윤하린 님의 마음에 접속하는 중…") + 팁 한 줄.

| 구분 | 이번에 구현 | 남김 (아트·결정 필요) |

## 5. 검증 결과 (2026-11-13)

| 검증 | 방법 | 결과 |
|---|---|---|
| 흐름 전체 | `FtueProbe` (헤드리스, 임시 세이브): 타이틀 → 프롤로그 → 방 5개 → 엔딩 → 결과 → 허브 해금·강화 → 재다이브(일시정지·전멸) | 37개 항목 통과, 실패 0 |
| 난이도 | `FtueSim` 강화 없이 자동 플레이 3회 (궁극기 자동, 유물은 첫 카드) | 3회 모두 방 5개 완주·분대 4명 생존. 8배속 약 90초 → 1배속 약 12분 |
| 화면 | `FtueCapture` (창, 1280x720) | `docs/ftue/` 32장 — 목록은 `docs/ftue/README.md` |
| 빌드 | `--export-release "Windows Desktop"` (워크트리 안 `build/windows/`) | ERROR 0, 새 스크립트·허브 배경이 팩에 포함, exe 기동 확인 |

읽을거리:
- 첫 의뢰는 **지금 밸런스로 무난히 완주**된다 (방마다 유물을 받는 영향이 크다). 첫 세션의 "이야기 보상 보장"에는 맞지만, 강화가 필요해지는 지점은 무한 야근과 다음 의뢰다. 첫 의뢰를 한 번쯤 지게 하고 싶다면 `VDRelicData`/`VDData.scaling` 이 아니라 의뢰 데이터에 방별 배율을 두는 쪽을 권한다.
- 자동 플레이는 패링을 하지 않는다. 사람이 하면 보스 방이 더 쉬워진다.

## 6. 결정이 필요한 것

1. **용어**: 전투 배너 "치료 시작/성공" 을 "정리 시작/완료" 로 바꿀지 (기획서 원칙 4). 새로 넣은 문구는 "다이브 · 접속 · 의뢰 · 정리" 로 썼다.
2. **허브 간판**: 배경 원화의 "REWIND ROOM" 이 그대로 보인다. 상담소 이름을 이쪽으로 정할지, 간판 없는 배경을 새로 받을지.
3. **재화 이름**: 결과·허브에 "시간의 결정", 전투에 "공허 정수" 가 그대로 노출된다.
4. **첫 의뢰 난이도**: 위 읽을거리 참고.
5. **새 아트 우선순위**: 하린 초상(표정 2종) → 엔딩 컷 3장 → 엽서 → 보스 진정 연출. 지금은 신호 파형·도형 카드가 자리를 잡고 있다.
