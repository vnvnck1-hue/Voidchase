# 실제 전투 캡처 위에 덧그린 사이버 유물 선택 화면

2026-11-12 사용자 교정: 게임 전체의 톤은 사이파이·사이버틱. 별도 판타지 공간을 만드는 대신 실제 전투 장면을 캡처해서 그 위에 덧그린다.

## 결과

| 파일 | 방향 | 효과 표현 |
|---|---|---|
| [01_comic_cyber.png](01_comic_cyber.png) | 코믹 사이버 | 굵은 검정 윤곽, 사선 패널, 라임색 선택 프레임, 청록 전류와 사각 입자 |
| [02_holo_interface.png](02_holo_interface.png) | 홀로그램 인터페이스 | 전장이 비치는 상단 패널, 육각 투영부, 스캔 라인, 우측 성좌판으로 이어지는 데이터 선 |

세 출력은 각각 1672×941. 내장 image_gen 편집 모드를 사용했고, 모두 동일한 원본 전투 캡처를 직접 입력했다. 이전 판타지 생성본은 입력하지 않았다.

## 캡처 근거

- 원본: [battle_capture.png](battle_capture.png), 1920×1080.
- 현재 프로젝트의 scenes/void_defense/VoidDefense.tscn을 Godot 4.7.2 Forward+로 실제 실행, 적 등장 후 start_battle()로 전투를 시작하고 2.8초 뒤 뷰포트를 캡처했다.
- [capture.gd](capture.gd), [Capture.tscn](Capture.tscn), [실행 로그](capture_stdout.log) 보관. 캡처용 파일은 docs 아래에만 추가했다.
- 로그에 전투 시작, 적 처치, 1920×1080 캡처 완료가 기록됐다. 표준 오류의 사용자 로그 경로·인증서 저장소 접근 경고와 별개로 이미지 렌더링·PNG 저장은 완료됐다.

## 시각 검수

- 세 결과를 각각 열어 원본 캡처와 비교했다. 전장의 카메라·플랫폼 형태·보라색 타일, 코믹 하프톤 배경, 상단 웨이브·정수 HUD, 오른쪽 육각 성좌판, 왼쪽 큰 캐릭터, 하단 네 초상의 배치를 식별할 수 있다.
- 전경 UI는 기존 화면의 보라·검정, 굵은 외곽선, 비스듬한 패널, 하프톤과 연결되도록 제작했다. 금장·룬·마법 제단 같은 이전 판타지 장식은 사용하지 않았다.
- 화면마다 정확히 카드 3장과 중앙 선택 상태, 유물 선택 제목, 세 유물명, 축약 수치, 선택 확정·새로고침이 보인다.
- 주요 한국어와 숫자를 육안 확인했다. 서리 결정: 둔화 40%·2초. 뇌운 조각: 평타 3회→번개 35. 별 깃털: 체력 50% 미만→보호막 25%.
- 01은 불투명한 코믹 패널, 02는 반투명 홀로그램, 03은 글리치 테두리로 차이를 두었다. 글리치와 발광이 주요 설명 문구를 가리지 않는다.
- 캐릭터 신규 제작·비례 수정은 지시하지 않았다. 최초 네 장과 캐릭터 지침을 확인한 뒤, 캡처 속 기존 캐릭터·초상은 재설계하지 않도록 편집 프롬프트에 고정했다. 카드에 가려진 부분은 직접 검수할 수 없으며, 생성 편집 결과를 원본과 픽셀 단위 동일하다고 주장하지 않는다.
- 결과는 정지 UI 콘셉트다. 효과 문구는 축약안이며, 실제 유물의 모든 조건·전투당 발동 횟수·배치 규칙을 설명하는 최종 구현용 문구는 아니다. 게임 코드·셰이더·실행 파일에는 적용하지 않았다.
