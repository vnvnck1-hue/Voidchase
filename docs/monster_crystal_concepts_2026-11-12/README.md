## 선화·명암 검수
- 굵은 짙은 윤곽과 가는 내부 면 분할이 분리되고, 발톱·뿔·촉수 끝으로 선이 가늘어지는 구간을 확인했다.

- 큰 셀 명암과 자홍색 핵이 형태를 구분한다. 결정 면에 추가 톤과 약한 질감이 있어 기준 캐릭터의 단순한 면색보다 묘사 밀도가 높다. 이는 사용자가 지정한 결정 몬스터 계열을 따르는 컨셉 표현이다.
- 배경의 종이 질감은 선 자체의 붓결 검수를 대체하지 않는다.
