# 로비 컨셉 v7 — Thick-line & Flat Shading / 구도 확장 3종

- 사용자 요청: v6의 스타일을 유지하며 다양한 구도, 더 풍부한 화면 구성.
- 내장 image_gen 사용. v6는 스타일·팔레트·시설 정체성 참고로만 사용하고 구도는 새로 구성.
- 큰 전경·중경·후경과 공간의 겹침으로 풍부하게 만들고, 작은 소품이나 거친 질감은 늘리지 않음.
- 각 장면의 약 35–40%는 메뉴 배치를 위한 낮은 디테일 밀도로 계획. 실제 UI 적용은 하지 않음.
- 3종: A 거리 모퉁이 외관 / B 내려가는 안뜰 / C 야간 접수실.

Witty economical TV animation shapes, clean and friendly, slightly angular, not realistic. No rough comic ink, hatching, halftone, scratches, grain, realistic materials, painted texture, intricate detail, blur/glow or volumetric rendering.

Moderate rich saturation, not all neon, no purple/green overload. Sparse simple star dots where sky is visible.
