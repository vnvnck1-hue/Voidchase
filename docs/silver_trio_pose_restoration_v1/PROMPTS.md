# 세 포즈 복원에 사용한 프롬프트

내장 image_gen 편집, 각 요청에 `transparent_background: true`. 포즈마다 별도 호출했다. 입력1은 `references/01_left_pose_reference.png` / `02_middle_pose_reference.png` / `03_right_pose_reference.png`, 입력2는 공통 `references/original_trio.png`.

원화 출력과 최종 PNG 대응:

- 왼쪽: `exec-dbdf240b-cc07-416a-b0e6-de0414cd23c2.png` → `png/01_left_pose.png`
- 가운데: `exec-a7983206-6393-4528-acf6-a8dd72a9eb02.png` → `png/02_middle_pose.png`
- 오른쪽: `exec-8dafc81a-a37b-4c06-bf37-e98ddf131313.png` → `png/03_right_pose.png`
