# 유물 선택 화면 콘셉트 생성 프롬프트

도구: 내장 image_gen. 요청된 세 방향을 각각 독립된 이미지로 생성.
사용자 첨부 두 장의 3택1 구조, 홀로그램 상단·어두운 정보 영역, 중앙 선택 강조를 시각 분석해 반영.
실제 유물명·축약 효과 문구는 scripts/void_defense/relics/vd_relic_data.gd 기준.
캐릭터를 포함하지 않는 UI 콘셉트 원화이며, 실제 셰이더나 게임 구현 변경은 포함하지 않음.

## 01_prismatic_constellation

Use case: ui-mockup
Asset type: polished Steam PC fantasy roguelite relic reward selection screen CONCEPT ART, one complete widescreen 16:9 game frame. Not a website, not a diagram, not a mood board. Render the aspirational visual quality of a real-time game using sophisticated node-based shaders and VFX. All labels in Korean.
Primary request: Design a relic choice screen for VOID DEFENSE. Exactly three large vertical relic cards centered horizontally with ample gaps; central card currently selected, slightly raised and enlarged. Each card contains an upper relic illustration chamber occupying about half its height, a bold name, a short legible effect description below, and a small hexagonal directional socket motif. Clean readable typography over dark quiet lower panels. Relic artwork should feel crafted, stylized fantasy 3D/2.5D in an anime-adjacent game world; NO people or character portraits.
Reference design language: reference one has three tall clipped-corner dark cards, opalescent cyan/lilac/pink upper chambers, a central hexagonal icon medallion, dark readable lower information areas, purple atmospheric backdrop; reference two has three suspended beveled plaques, purple side-card perimeter energy, luminous gold selected center, sparse particles and subtle occult patterns behind, confirmation below. Preserve the clear three-way choice hierarchy and premium glow response, invent original frames, artwork, background and UI rather than copying the references.
Composition: generous upper heading zone; card row fills about 65% screen height; all UI safely within frame, no cropping; restrained footer with reroll left, large primary confirmation center and currency right. Cards front facing with subtle dimensionality. Center selected state obvious via silhouette lift and stronger illumination; side cards fully readable. Design direction 01 — PRISMATIC CONSTELLATION. Sleek celestial crystalline fantasy: a rich deep indigo void with a subtly blurred vast constellation disc and a low luminous horizon. Architectural faceted card frames made of dark midnight glass and fine silver inlay, clipped corners, subtle pearlescent iridescent edge bevels. Upper relic chambers have thin-film rainbow interference and opal refraction in cyan, lilac, rose. The central card has a warm champagne-gold perimeter traced by elegant streaming highlights; electric cyan thunder floating in a hexagonal crystal seal. Left frost and right feather illuminated in restrained lilac. Shader/VFX visual signature: gorgeous anisotropic spectral sweeps, refracted caustic bands crossing glass, tiny stardust motes in curved orbit, faint holographic hex layers with parallax, sparse soft volumetric light shafts behind the selected card, minimal bloom confined to luminous highlights. Modern elegant premium anime fantasy PC game UI, luxurious rather than overornamented. Primarily clean horizontal composition, NOT a noisy fireworks screen. Wide 16:9.
