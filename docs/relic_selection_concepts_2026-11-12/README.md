## 레퍼런스와 구성

사용자 제공 두 이미지는 references/에 원본 보관. 첫 이미지의 오팔빛 상단·어두운 설명 영역·세로 카드 3장을, 두 번째 이미지의 중앙 선택 금빛 강조·좌우 보라색 에너지·하단 확정을 구성에 반영했다. 원화마다 프레임 재질과 공간 연출을 달리했다.

세 장은 동일 유물과 문구로 비교할 수 있게 통일했다. 현재 vd_relic_data.gd의 서리 결정·뇌운 조각·별 깃털을 사용했다. 효과는 콘셉트 화면용 축약 문구이며 전체 규칙과 배치 조건을 모두 기재한 최종 UI 카피는 아니다.

## 시각 검수

- 세 원화를 각각 열어 확인했다. 각 이미지 1672×941, 가로형 16:9에 가까운 구도.

- 한국어 주요 문구와 표시 수치(둔화 40%·2초, 평타 3회·번개 35, 체력 50%·보호막 25%)를 확인했다.
- 효과는 주로 그림 영역과 프레임·배경에 있고 설명 영역은 어둡게 분리되어 있다. 잘린 주요 UI는 없다.
- 01은 광택과 굴절, 02는 무거운 조각 프레임과 제단, 03은 유리와 데이터 홀로그램으로 방향이 구분된다.
- 육각 화살표·인접 칸 도식은 콘셉트 장식이며 실제 소켓 방향·수량과 일치하지 않는다. 구현용 추출 시 실제 데이터 기준으로 다시 그려야 한다.
- VFX는 정지 원화에 표현된 목표 모습이다. 실제 애니메이션·셰이더 동작·성능을 검증한 결과가 아니다.
