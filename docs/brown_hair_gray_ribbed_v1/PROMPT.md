# 실제 생성 프롬프트

내장 image_gen 사용. 입력1은 `construction_and_design.png`, 입력2~5는 프로젝트 최초 원화 그룹22/그룹30/그룹32/레이어193. 최종 출력 `exec-1d70779a-12ba-4ec8-943b-e6c649263703.png`를 `brown_hair_gray_ribbed_final.png`로 보관했다. 최종본은 이 한 장이다.

새 게임 캐릭터 전신 원화 한 장을 처음부터 그린다.

입력1 왼쪽의 초기 인체 가이드를 바탕으로, 입력2~5의 최초 게임 원화와 동일한 그림체/인체 구성으로 그린다. 입력1 오른쪽은 외형 디자인만 참고한다. 원본의 실제 성인 인체와 구도/크롭을 복사하지 말고, 같은 성인 캐릭터를 우리 게임의 SD 카툰으로 재해석한다. 이전 생성 캐릭터는 사용하지 않는다.
전신 정수리~신발바닥은 주 머리 정수리~턱 H의 약2.72배, 허용 범위2.67~2.80H. 가이드처럼 머리1H, 턱 아래~가랑이 약0.85H, 가랑이~발바닥 약0.87H의 공간에 처음부터 자연스러운 인체를 구성한다. 길쭉한3~4등신 패션모델 인체가 아니다. 머리는 넓은 타원과 경사진 턱 면, 눈은 정상적인 타원, 목~어깨~골반~무릎 연결이 자연스럽게. 완성 그림을 눌러 변형하거나 머리카락의 외곽 폭을 맞추려고 얼굴을 납작하게 만들지 않는다.

새 외형:
정면 참고의 **긴 갈색 생머리**를 선택한다. 짧고 반듯하게 잘린 두꺼운 일자 앞머리, 옆머리와 긴 뒤머리는 매끈한 큰 덩어리로 허리 아래까지. 모발 잔선 대신 큰 면과 적은 하이라이트. 따뜻한 갈색 홍채, 반쯤 내려온 굵은 윗눈꺼풀, 무심하고 자신감 있는 작은 입, 따뜻한 복숭아/살구빛 피부와 분홍 볼.
크고 단순한 은색 링 귀걸이 한 쌍.
회색 골지 하이넥 크롭 볼레로: 목을 감싸는 짧은 터틀넥과 긴 소매, 가슴 위쪽에 가로로 트인 디자인. 아래에는 같은 회색의 짧은 이너탑으로 가슴을 완전히 가린다. 허리에 좁은 피부색 간격이 있고, 같은 회색 하이웨이스트 레오타드형 하의로 이어진다. 하의의 다리 트임은 단순하고 선명한 곡선. 원래 의상 디자인을 유지하되 사실적인 가슴/엉덩이/허벅지의 입체 묘사나 강조 없이 작은 카툰 인체의 간결한 의상 면으로 그린다. 불투명한 옷, 노출된 가슴이나 생식기 없음.
골지 질감은 각 큰 의상 면에 몇 개의 가는 밝은 세로선으로만 표현한다. 조밀한 패턴을 넣지 않는다.
원본에 안 보이는 하반신을 자연스럽게 완성: 따뜻한 피부색 다리와 단순하고 단단한 짙은 회색 캐주얼 앵클부츠. 신발은 납작하거나 길게 늘어진 형태가 아니라 실제 발 방향에 맞는 정상적인 카툰 형태다.

한 손은 허리에 가볍게, 다른 손은 옆에 편하게 내려간 새 안정적인 스탠딩. 한 다리에 무게를 두고 반대쪽 발끝은 약간 밖으로. 약한3/4 정면, 머리 기울기는 작게. 뒷모습/핀업 포즈/분할화면 없이 한 인물의 자연스러운 게임 대기 포즈. 손가락/팔꿈치/의상 접힘과 신발 원근을 그 자세에 맞춰 새로 그린다.

입력2~5와 같은 굵은 검정 외곽선, 선택적인 얇은 내부선, 넓은 색면,1~2단계 경계가 분명한 셀 그림자, 작은 단순 하이라이트. 성격은 얼굴의 눈꺼풀/눈썹/입으로 표현한다. 그라데이션·광택 피부·3D 조명·현실적인 코와 입술·미세모발·픽셀 스타일 없음.
흰 배경의 완성 전신 한 명, 머리와 양발 전부 보이고 사방에 여백. 글자·로고·치수·가이드·효과·비교표·테두리·워터마크 없음.
