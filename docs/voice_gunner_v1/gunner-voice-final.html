건너 — 게임에 넣은 추임새 (적용본)

2차에서 고르신 결과대로 스킬 8개 · 피격 7개를 게임에 넣었습니다. 여기서 듣는 소리는 게임 폴더 assets/audio/void_defense/voice/의 파일 그대로입니다.

  • 음절 편집: "하잇!"·"히앗!"은 첫 음절만, "큿!" 테이크 1은 하나로, "흣·휴"와 "큿!" 테이크 2는 음절마다 따로 나눴습니다(0.16~0.36초).
  • 스킬: 건너가 다중 사격을 쓸 때 8개 중 하나. 피격: 건너가 피해를 받을 때 7개 중 하나. 맞을 때마다 나오면 시끄러워서 같은 캐릭터는 1.2초에 한 번만 냅니다.
  • 뺄 소리는 체크를 풀고, 고칠 점은 코멘트로 남긴 뒤 결과 복사로 붙여 주세요.
확인한 것
  • Godot 헤드리스 임포트 후 VDAudio 가 스킬 8·피격 7개를 읽음. 피격 두 번 연속 → 추임새 1번(쿨다운), 목소리 없는 영웅(마법사 등)은 조용히 건너뜀.
  • 실제 전투 씬에서 건너에게 피해 → voice_gunner_hurt 1회. VDRunner 전투 4사이클: 건너 스킬 시전 수 = voice_gunner_skill 재생 수, 스크립트 오류 없음.
  • 음절 자르기: 원본에서 20ms 음량이 최대치 -30dB 넘는 덩어리를 하나씩, 앞뒤 10ms, 피크 -3dB, 끝 40ms 페이드 (cut.mjs).
