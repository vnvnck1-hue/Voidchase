# 타일 글리치 — 마음속 디지털 세계 (2026-11-11)

전투 필드 타일이 가끔 혼자 '치지직'거린다. 이곳이 의뢰인의 마음을 옮긴 디지털 세계라는 느낌을 바닥에 넣는 연출.

- 코드: `scripts/void_defense/vd_tile_glitch.gd` (VDTileGlitch, 보드 바로 위·바닥 이펙트 아래) + `shaders/tile_glitch.gdshader`
- 고르기: 설정 메뉴 [타일 글리치] 또는 전투 중 **F4** (끄기 → 신호 잡음 → 데이터 붕괴 → 기억 홀로그램). `user://vd_tile_glitch.cfg` 에 저장.
- 테마(공허/사막)와 무관: 타일 아래 화면을 읽어 비틀기 때문에 타일 그림이 바뀌어도 그대로 동작한다.

## 프리셋 3종

| 프리셋 | 느낌 | 움직임 |
|---|---|---|
| 신호 잡음 | 가로 띠가 밀리고 청록/자홍으로 색이 갈라지는 방송 잡음 | `desert_signal.gif` · `void_signal.gif` |
| 데이터 붕괴 | 타일이 등각 픽셀 블록으로 깨지고 일부는 비트 무늬의 빈 데이터로 | `desert_data.gif` · `void_data.gif` |
| 기억 홀로그램 | 타일이 와이어프레임 홀로그램으로 바뀌고 뇌파 파형이 지나간다 | `desert_holo.gif` · `void_holo.gif` |

- `presets_desert.png` · `presets_void.png`: 세 프리셋 나란히 (왼쪽부터 신호 잡음 / 데이터 붕괴 / 기억 홀로그램)
- `<테마>_<프리셋>_dense.png`: 잘 보이게 지직거리는 타일 수를 7배로 늘린 정지 화면. GIF 는 실제 빈도.

## 함께 넣은 것

- **기억 스캔선**: 깊이 방향으로 전장을 훑는 옅은 빛 (홀로그램 프리셋에서 더 진하다).
- **충격 물결**: 강타는 그 칸만, 처치·내려찍기·보스 처치는 그 지점에서 타일 단위로 글리치가 번진다 (`pulse_*.gif`).
- **구역 로딩**: 새 방·복도가 다 솟아오르면 분대 쪽에서 새 타일로 물결이 한 번 지나간다. 전투 입장 때도 한 번.
- **바닥 기억 로그**: 현재 방의 한 칸에 "기억 조각 #3F2", "…괜찮아" 같은 글자가 바닥에 누운 채 잠깐 찍힌다 (`memory_log.gif`). 설정 [바닥 기억 로그] 로 끈다. 문구는 `LOG_LINES` (진단명·무거운 말 금지 — 네러티브 기획서 소재 원칙).
