|---|---|---|
| A · 카드 메이드 | 별 카드를 안은 작은 메이드 | 준비 → 점프 → 체공 → 착지 → 리본 정리 |
| B · 왕관 공허젤리 | 떠 있는 왕관을 쓴 말랑한 공허 마스코트 | 몸 눌림 → 늘어남 → 왕관 지연 → 졸린 눈 → 복귀 |

- 원본 크기가 열·행 수로 나누어떨어지지 않아 미리보기는 각 경계를 반올림해 표시합니다. `sheets.json`에 실제 정수 픽셀 영역이 있습니다.
- 시안 검토용입니다. 실제 게임에 연결하기 전 선택한 디자인의 실루엣 변화와 발·중심 기준점을 다듬고, 균일 셀 규격 및 필요 시 투명 배경으로 제작하는 것이 다음 단계입니다.
