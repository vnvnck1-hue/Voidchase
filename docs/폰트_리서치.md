# 폰트 리서치 — 상업적 무료 한글 폰트 (우리 게임 스타일 기준)

작성일: 2026-11-09 · 상태: **조사 완료, 선택 미결** · 대상: 로비·VOID DEFENSE 전체 UI

> 기준 스타일: 굵은 외곽선 플랫 카툰, 보라·분홍·청록 네온, 치비 캐릭터, 만화 효과음·말풍선, 전 씬 CRT 오버레이
> (`assets/컨셉 원화/로비_야간상담소`, `docs/lobby_cartoon_concepts_v11`, `docs/crt`). 네러티브 톤은 "가벼운 일상 개그 + 작은 감동"(`docs/네러티브_기획서.md`).

---

## 1. 한 줄 결론

**제목·효과음은 배민 도현체/주아체 또는 여기어때 잘난체, UI 본문은 Pretendard 또는 넥슨 Lv.2 고딕, CRT·글리치 연출은 Galmuri, 말풍선은 배민 연성체 또는 나눔손글씨**로 가면 라이선스 걱정 없이 지금 컨셉 아트 톤을 그대로 살릴 수 있다. 위 폰트는 전부 폰트 파일을 게임에 동봉(임베딩)해 상업 배포하는 것이 **공식 원문으로 허용**되어 있다.

## 2. 현재 상태 진단 (왜 바꿔야 하나)

| 항목 | 현재 | 문제 |
|---|---|---|
| 한글 UI 전체 | `VDData.font()` 가 `SystemFont`(맑은 고딕 → Noto Sans KR → sans-serif)를 반환. 로비·배틀·유물 HUD·배너 부제 전부 이걸 씀 | **맑은 고딕은 Windows 번들 MS 소유 폰트**라 게임에 동봉할 수 없고, 지금은 플레이어 PC에 설치된 폰트에 의존한다. 다른 OS나 폰트가 없는 환경에서는 모양이 바뀌거나 두부(□)가 난다. 카툰 톤과도 어울리지 않는다. |
| 제목·데미지 숫자·로딩 화면 | `assets/fonts/ARCO.otf` (대문자 전용 라틴 디스플레이) | dafont 작성자 노트에 "개인·상업 사용 무료"라고만 있고 **정식 라이선스 문서(OFL 등)가 없다.** 소문자·한글이 없어 한글은 전부 시스템 폰트로 떨어진다. |
| 배너 제목 | ARCO + 맑은 고딕 900 폴백 (`vd_banner.gd`) | 라틴과 한글의 굵기·높이가 따로 논다. |
| 유물 툴팁 제목 | SystemFont 맑은 고딕 800 (`vd_relic_hud.gd`) | 위와 동일. |

→ **폰트 파일을 프로젝트에 넣고 `FontFile` + `fallbacks` 로 묶는 것**이 이번 리서치의 실제 적용 목표다.

## 6. Godot 4.7 적용 메모

1. **파일 배치**: `assets/fonts/<폰트명>/` 아래 TTF/OTF 와 **라이선스 전문(OFL.txt 또는 저작권 안내)** 을 함께 둔다. 배민·잘난체·넥슨은 "라이선스/저작권 안내 포함"이 번들 조건이다. `.txt` 는 리소스가 아니라 "all_resources" 내보내기에 저절로 들어가지 않는다 → 프리셋 포함 필터 `assets/fonts/*LICENSE.txt` 로 팩에 넣는다 (2026-11-09 설정).
2. **`VDData.font()` 교체**: `SystemFont` 대신 `load("res://assets/fonts/.../Pretendard-Regular.otf")` 를 기본으로, `fallbacks` 에 라틴 디스플레이·픽셀 폰트·마지막에 기존 SystemFont 를 넣는다. 로비(`lobby.gd`)·씬 전환기·배틀(`vd_battle.gd`)·유물 HUD 는 전부 이 함수를 쓰므로 한 곳만 바꾸면 된다. 배너(`vd_banner.gd`)·로딩(`loading_screen.gd`)·데미지 로그(`vd_damage_log.gd`)·유물 배지는 ARCO 를 직접 load 하므로 따로 바꾼다.
3. **굵기**: `FontVariation` 의 `variation_embolden` 대신 실제 Bold 파일을 쓴다. 한글은 가짜 굵게가 뭉개진다.
4. **힌팅 vs MSDF**: 본문(12~20px 한글)은 MSDF 끄고 힌팅 Light + 서브픽셀 위치. 배너·컷인처럼 크게 키우거나 외곽선을 두르는 글자만 MSDF (`msdf_pixel_range` ≥ 외곽선 두께 ×2). 겹치는 윤곽이 있는 디스플레이체는 MSDF 에서 깨질 수 있다.
5. **픽셀 폰트**: Galmuri·Neo둥근모는 안티앨리어싱 끄고, 힌팅 None, 크기는 기준 픽셀의 정수 배(11·22·33 / 16·32·48)만. CRT 셰이더의 정수 간격(`crt-screen-effect` 메모)과 같은 배율로 맞추면 주사선과 글자가 같이 떨어진다.
6. **용량**: 한글 11,172자 OTF 는 굵기당 1~3MB. A안 전체(도현·한나·Pretendard 3종·풋볼 Bold·Galmuri 2종·연성)는 약 10~15MB 로 단일 exe 에 넣어도 부담 없다.
7. **출처 표기**: 설정/크레딧 화면에 한 줄씩 — 예: "이 게임에는 ㈜우아한형제들이 제공한 배달의민족 도현체, 넥슨코리아의 넥슨 풋볼 고딕이 적용되어 있습니다." 배민·넥슨·잘난체 모두 출처 표기를 "권장"으로 둔다.

## 6-1. 시식 페이지

`docs/fonts/index.html` — 한글 50여 종 + 영어 75종(카툰·네온/레트로/SF·픽셀·손글씨·UI, 전부 Google Fonts OFL)을 웹폰트(CDN)로 불러와 게임 문장·숫자·말풍선·HUD 목업으로 보여 주는 비교 페이지. 파일을 받지 않고 미리보기만 한다.
`python docs/fonts/serve.py` (포트 8765, `.claude/launch.json` 의 `fonts`)로 띄우면 카드마다 **☆ 후보** 버튼과 코멘트 칸이 `docs/fonts/comments.json` 에 자동 저장된다. 서버 없이 그냥 열면 브라우저에만 남고 "comments.json 내려받기"로 뺄 수 있다. 맨 아래 "코멘트 모아보기"가 마크다운 정리본. 상단 입력창으로 한글·영어 시식 문장을 바꾸고, A/B/C/D 버튼으로 조합 목업을 전환한다(D = 카툰 네트워크). 4·5장이 카툰 네트워크 스타일(영어 72 · 한글 44)이고, 목업의 흑백 체커 로고가 제목 폰트를 따라 바뀐다.

**설정창에서 바꾸기** — 톱니 설정 메뉴의 **[글꼴 조합]** 으로 미리 짠 6개 조합 중 하나를 고르거나, **[글꼴 바꾸기 (F5)]** 패널에서 역할별로 고른다. 고르는 즉시 열려 있는 화면 전체가 바뀌고 `user://fonts.cfg` 에 저장된다.
- 역할 3개: **본문**(UI 글자 대부분, `VDData.font()`), **강조**(큰 버튼·컷인 이름·툴팁 제목·스킬창), **숫자·타이틀**(피해 숫자·배너 제목·로딩·READY! 팝, 원래 ARCO, `VDDamageLog.font()`).
- 역할마다 **한글 글꼴**(맑은 고딕 · 카트 고딕 · 스웨거 · 양진 · 와구리)과 **영어·숫자 글꼴**(한글 글꼴 그대로 · ARCO · 영어 9종)을 따로 고른다. 영어 글꼴에 없는 한글은 한글 글꼴로, 거기도 없는 글자는 시스템 고딕으로 이어진다.
- 기본값은 바꾸기 전 모습(맑은 고딕 + ARCO) 그대로다.
- 코드: `scripts/game_fonts.gd`(역할·후보·조합 표, 저장), `scripts/font_tuner.gd`(패널), `scripts/scene_switcher.gd`(메뉴 항목·F5). 역할 글꼴은 같은 FontVariation 객체를 계속 쓰고 안의 글꼴만 바꿔서, 이미 떠 있는 Label·LabelSettings·테마도 다시 만들지 않고 바뀐다.
- 아직 역할을 안 따르는 곳: 전투 오른쪽 위 "W1 - S1" 스테이지 글자(시안 글꼴 Sarina 자리, 없어서 Segoe Script 로 그림).
- 검사·캡처: `tools/test/FontProbe.tscn` (헤드리스 검사, 창이면 `docs/fonts/game/` 에 로비 6조합 · 전투 캡처).
