# 네러티브 기본 골자 — 컨셉 아이디에이션

작성일: 2026-11-06 · 상태: **아이디에이션 (원본 자료)** · 정리본: `docs/네러티브_기획서.md` (F 「마음 정리 상담소」 채택)

> 전제: 우리 게임은 무겁지 않다. 치비 그림체, "BANG!" 같은 만화 효과음, 메이드 중심의 분대, 말풍선 툴팁(`화면 컨셉_2`).
> 그래서 서사는 **"한 줄로 설명되고, 실패해도 웃기고, 시스템 이름이 그대로 설정이 되는"** 쪽을 고른다.
> 비장한 세계 멸망 서사, 긴 컷신, 텍스트 덤프는 하지 않는다.

## 0. 이미 있는 재료 (서사가 반드시 받아줘야 하는 것)

| 재료 | 현재 상태 | 서사가 답해야 할 질문 |
|---|---|---|
| 공허 유적 | 보라 하늘·큰 달·떠다니는 석조 플랫폼 | 여긴 어디고, 왜 떠 있나? |
| 공허 잔재·파편·결정체·포자, 공허 군주 | 눈 달린 검은 슬라임, 왕관 쓴 촉수 덩어리 | 얘네는 뭐고, 왜 몰려오나? |
| 분대 4인 (기사/건너/마법사 메이드/힐러 메이드) + 쇼룸 7인 | 이름 미정, 멜빵 소녀(char_02)가 좌하단 대표 | 왜 이 애들이 싸우나? 왜 메이드인가? |
| 별 깃발 거점 | 좌측 방어선 | 무엇을 지키나? |
| 방 단위 전진 + 갈림길 | 그레이박스 루프 | 왜 앞으로 가나? |
| 유물 성좌판 (육각 10칸, 방마다 +1 해금, 침식 칸) | 1차 구현 | 유물은 뭐고 왜 별자리 판에 끼우나? 침식은 뭔가? |
| 공허 정수 (런 재화) / 시간의 결정 (영구) | 기획안 확정 | 왜 모으나? |
| 전멸 = 런 종료, 영구 성장 유지 | 로그라이트 구조 | 실패를 어떻게 가볍게 처리하나? |

## 1. 컨셉 A — 「공허 청소 대행 메이드단」 ★추천

**로그라인:** 하늘에 떠 있는 낡은 저택 유적에 "공허 얼룩"이 번졌다. 우리는 시급 받고 치우러 온 메이드 청소 업체다.

- **세계:** 공허 유적은 원래 어떤 대마법사의 하늘 저택. 주인이 사라진 뒤 방치돼 "공허 먼지"가 쌓였고, 먼지가 뭉쳐 눈 달린 슬라임이 됐다.
- **동기:** 거창한 사명이 아니라 **의뢰**다. 저택을 되찾고 싶은 의뢰인(말하는 달, 또는 저택의 집사 유령)이 청소 업체 "별빛 메이드단"을 부른다.
- **왜 메이드:** 그냥 직업이 메이드라서. 기사·건너도 "청소부 조끼만 걸친 외주 인력"이라 섞여도 어색하지 않다.

| 시스템 | 서사 매핑 |
|---|---|
| 런 1회 | 의뢰 1건 ("3층 동쪽 날개 청소") |
| 방 전진·갈림길 | 저택의 방들 (서재, 온실, 무도회장…). 갈림길 = "어느 방부터 치울까요?" |
| 공허 잔재 | 먼지 뭉치. 처치 = 청소 완료 (죽음 연출 대신 "뽀득!" 소멸) |
| 공허 군주 | 저택에서 제일 오래 묵은 먼지 덩어리. 왕관은 주인의 잃어버린 모자 |
| 유물 | 저택에서 주운 골동품. "이거 써도 돼요?" "써. 청소비에서 안 깎을게" |
| 성좌판 | 메이드 장의 **업무 배치표**(별자리 모양 근무표) |
| 침식 칸 | 판에 묻은 얼룩. 지우면(정화하면) 칸 복구 |
| 공허 정수 | 일당 / 시간의 결정 = 연차 포인트(성장) |
| 전멸 | "오늘 근무 끝! 내일 다시 와요" → 퇴근 컷인 |
| 별 깃발 | 업체 깃발 = 청소 완료 구역 표시 |

- **톤 예시:** 힐러 "다친 데 없죠? 산재 처리 귀찮으니까." / 마법사 "얼려두면 닦기 쉬워요."
- **장점:** 그림(메이드, 멜빵 작업복 소녀)과 바로 맞물림. 실패가 '퇴근'이라 스트레스가 없다. 방마다 개그 소재(지하 와인 창고, 고장 난 피아노)가 끝없이 나온다.
- **약점:** '공허'라는 이름의 무게감이 조금 깎인다. → 로고는 VOID DEFENSE 그대로 두고 부제로 개그를 준다 (예: *공허 유적 청소 대작전*).

## 2. 컨셉 B — 「떨어진 별자리 줍기」

**로그라인:** 어젯밤 하늘의 별자리가 통째로 공허에 쏟아졌다. 별을 주워 밤하늘을 다시 꿰매는 '별지기' 소녀들의 이야기.

- **세계:** 큰 달은 밤하늘의 관리인. 공허(하늘 아래 쓰레기통 같은 곳)에 별 조각이 떨어지자 슬라임들이 반짝이는 걸 좋아해 삼켜버렸다.
- **동기:** 달이 "오늘 밤 안에 '고양이자리'를 복구해줘"라고 부탁한다. 런마다 목표 별자리가 있다.

| 시스템 | 서사 매핑 |
|---|---|
| 유물 성좌판 | **이 컨셉의 핵심.** 유물 = 별 조각. 판을 채우는 일 = 별자리를 다시 꿰매는 일 |
| 방 +1 칸 해금 | 별 하나 되찾을 때마다 별자리가 한 칸씩 밝아짐 |
| 침식 칸 | 공허 얼룩에 덮인 별 |
| 공허 군주 | 별을 제일 많이 삼켜서 왕관처럼 반짝이게 된 대장 슬라임 (처치하면 별을 토해냄) |
| 메타 진행 | 별자리 도감. 하나 완성할 때마다 짧은 별자리 우화 1편 해금 |
| 전멸 | "아침이 와버렸어!" → 달이 지고 런 종료 |

- **장점:** 이미 정한 "유물 성좌판"·별 깃발·큰 달과 이름이 그대로 이어진다. 동화톤이라 수집 욕구와 잘 맞는다.
- **약점:** 귀엽지만 개그 밀도는 A보다 낮다. 캐릭터 간 티키타카보다는 세계 분위기 중심.

## 3. 컨셉 C — 「낮잠 원정대」 (꿈속 방어전)

**로그라인:** 주인공(=플레이어)이 낮잠만 자면 악몽이 몰려온다. 꿈속 수호 소녀들이 베개 성(=유적)을 지킨다.

- **세계:** 공허 = 악몽, 유적 = 잠든 사람의 꿈 풍경. 떠다니는 돌·큰 달이 "꿈이라서"로 전부 설명된다.
- **동기:** 플레이어를 푹 재우는 것. 슬라임은 "내일 마감", "안 끈 가스불" 같은 걱정의 형상.

| 시스템 | 서사 매핑 |
|---|---|
| 런 1회 | 낮잠 한 번 |
| 방 전진 | 꿈이 더 깊어지는 것 (얕은 잠 → 렘수면 → 깊은 잠) |
| 공허 군주 | 그날의 가장 큰 걱정 (보스마다 이름이 다른 개그: "월요일", "미답장 메시지") |
| 유물 | 꿈속 소지품 (애착 인형, 따뜻한 우유) |
| 전멸 | 잠에서 깸 → "알람 5분만…" 이어하기 연출 |

- **장점:** 실패 처리가 가장 자연스럽다. 보스 네이밍 개그로 업데이트할 때마다 콘텐츠가 쉽게 늘어난다. 플레이어를 '자는 사람'으로 두면 미소녀들과의 관계가 바로 생긴다.
- **약점:** '플레이어 = 주인님' 구도가 강해져 취향을 탄다. 공허 원화의 SF·판타지 감각과는 조금 거리가 있다.

## 4. 컨셉 D — 「공허 유적 생중계」 (탐사 방송)

**로그라인:** 인기 없는 마법 방송 채널의 4인조가 조회수를 위해 위험한 공허 유적 탐사 생방송을 켰다.

- **세계:** 공허 유적은 실제로 위험한 곳. 다만 분대에게는 '각 나오는 촬영지'일 뿐이다.
- **동기:** 구독자 늘리기. 공허 정수 = 후원, 시간의 결정 = 구독자 수(채널 성장).

| 시스템 | 서사 매핑 |
|---|---|
| "BANG!" 효과 | 방송 자막 그대로. 원화의 만화 효과음이 세계관 안에서 설명된다 |
| 말풍선 툴팁 | 시청자 채팅 / 편집자 자막 |
| 갈림길 | 시청자 투표 ("오른쪽 방 가주세요!!") |
| 유물 | 시청자가 보낸 후원 아이템 |
| 공허 군주 | 이번 회차 '썸네일 몬스터' |
| 전멸 | "방송 사고" 화면 → 다음 회차 예고 |

- **장점:** 이미 그린 UI(효과음, 말풍선)가 그대로 세계관 요소가 된다. 짧은 채팅 한 줄로 상황 설명·튜토리얼·개그를 다 처리할 수 있다.
- **약점:** 현대 방송 밈이라 유통기한이 짧을 수 있고, 판타지 유적 그림과 톤 충돌 위험이 있다.

## 5. 컨셉 E — 「공허 군주는 친구가 없다」 (반전 한 스푼)

**로그라인:** 매일 쳐들어오는 공허 군주는 사실 같이 놀 친구를 찾는 꼬마다. 너무 세게 놀자고 해서 문제일 뿐.

- 기본 플레이는 A~D 어디에나 얹을 수 있는 **메인 떡밥**. 단독 컨셉보다는 '엔딩 방향'으로 쓴다.
- 처치 대신 "진정시키기". 쓰러진 슬라임은 작아져서 거점 깃발 옆에 모인다 (터치 게임 데모의 몬스터 클릭 → 쓰다듬기 미니게임으로 재활용 가능).
- 기획안의 "공허 군주 토벌 엔딩"을 "공허 군주와 화해" 엔딩 + 무한 모드(같이 놀기)로 바꾼다.
- **장점:** 무겁지 않은 엔딩을 보장한다. 몬스터 도감·펫 수집으로 확장하기 쉽다.

## 5-1. 컨셉 F — 「마음 정리 상담소」 (사용자 제안, 2026-11-06)

**로그라인:** 마음이 어질러진 의뢰인의 마음속에 들어가, 엉킨 생각을 치우고 잃어버린 좋은 기억을 되찾아 주는 메이드 상담소.

### 왜 잘 맞나 — 시스템이 거의 그대로 은유가 된다
| 시스템 | 서사 매핑 |
|---|---|
| 런 1회 | 의뢰인 1명의 마음 방문 1회 (= 상담 1회기) |
| 공허 유적 | 그 사람의 **마음 풍경**. 의뢰인마다 테마가 다름 (시험 앞둔 학생 → 무너진 도서관, 무대 공포 가수 → 텅 빈 공연장) |
| 방 전진·갈림길 | 기억의 방들. 갈림길 = "어느 기억부터 들여다볼까?" |
| 공허 잔재 | **엉킨 생각·잡념** ("나만 뒤처졌어", "다들 날 싫어할 거야"). 사람이나 병 자체가 아니라 '어질러진 것' |
| 공허 군주 | 그 사람의 가장 큰 **응어리**. 쓰러뜨리지 않고 진정시키면 작아져서 원래 모습(상처받은 기억)이 드러남 → E의 화해 엔딩과 같은 구조 |
| 유물 | 의뢰인의 **좋은 기억 조각** (첫 무대 박수, 할머니의 도시락) |
| 유물 성좌판 | **마음의 별자리**. 좋은 기억을 끼울수록 마음 하늘이 밝아짐. 방마다 +1 칸 = 기억 하나씩 되찾기 |
| 침식 칸 | 부정적인 생각에 덮여 안 보이는 기억. 정화하면 다시 쓸 수 있음 |
| 별 깃발 거점 | 의뢰인의 **안전 기지**(마음속 가장 편한 장소). 실제 상담에서도 쓰는 개념이라 설정이 단단해짐 |
| 분대 전멸 | "오늘 상담 시간은 여기까지." 실패가 아니라 다음 회기 예약 |
| 런 반복 + 영구 성장 | **회복은 한 번에 되지 않는다.** 로그라이트 반복 자체가 메시지가 된다 (이 컨셉의 가장 큰 장점) |
| 시간의 결정 | 상담소 경험치 / 의뢰인과 쌓은 신뢰 |

- **왜 메이드:** 마음속도 결국 '집'. 상담소 간판은 "마음 정리 대행". A의 청소 메이드단을 그대로 흡수한다.
- **의뢰인 단위 콘텐츠:** 의뢰인 1명 = 스테이지 1개 (테마 배경, 전용 잔재, 보스 응어리, 엔딩 컷 1장). 업데이트 단위로 딱 맞다.

### 위험 요소와 원칙 (가볍게 가려면 반드시 지킬 것)
| 위험 | 원칙 |
|---|---|
| 실제 질환(우울증, 조현병 등)을 몬스터로 치고 부수면 낙인·희화화로 읽힐 수 있음 | **진단명을 쓰지 않는다.** '정신질환 치료' 대신 '고민·마음 정리'로 표현. 소재는 일상적인 것 위주 (시험 불안, 번아웃, 이별, 무대 공포, 외로움) |
| "때려 부수면 낫는다"는 메시지 | 적은 '그 사람'이 아니라 '엉킨 생각'. 마지막 단계는 분대가 아니라 **의뢰인 본인이 문을 연다** (회복의 주체는 의뢰인) |
| 미소녀가 마법으로 치료해 주는 구도가 실제 치료를 가볍게 보이게 함 | 분대는 의사가 아니라 '정리 도우미'. 엔딩에서 의뢰인이 친구·가족·전문가에게 말을 꺼내는 쪽으로 마무리 |
| 무거운 소재가 섞이면 톤 붕괴 | 자해·자살·학대는 다루지 않는다 |
| 플랫폼 심의·평점 | 게임 시작 시 짧은 안내 1줄 + 설정 메뉴에 상담 기관 안내 링크 정도는 고려 |

- **톤 예시:** 건너 "이 생각, 세 번째 방에서도 나왔어요. 끈질기네." / 힐러 "다 치우진 않아도 돼요. 걸려 넘어지지 않을 만큼만."

> 2026-11-06 갱신: 사용자 제안 **F (마음 정리 상담소)**가 아래 조합(A + B + E)을 하나의 설정으로 흡수한다. 현재 1순위는 F. 아래는 F 이전의 추천안이다.

**(이전) 추천 조합: A + B의 이름 + E의 엔딩**
- 몸통은 **A (청소 대행 메이드단)**: 메이드 중심의 그림과 가볍고 웃긴 톤이 가장 직접 맞는다.
- 업체 이름과 유물판은 **B에서 빌린다**: 업체 이름 "별빛 메이드단", 유물판은 단장이 쓰는 '성좌 근무표'. 저택 주인(사라진 대마법사)이 별 연구가였다는 설정이 있으면 별 깃발·큰 달·성좌판이 한 줄로 이어진다.
- 끝은 **E**: 마지막 방의 공허 군주 = 주인이 남기고 간 외로운 애완 먼지. 엔딩은 "새 식구 입주".

## 7. 어떤 컨셉이든 공통으로 쓰는 골자

### 7-1. 3막 (전체 플레이를 통틀어 아주 얇게)
1. **도입 (첫 런, 1분 이내):** 의뢰·목표 한 줄 + 분대 4인의 자기소개 대사 한 마디씩. 바로 전투.
2. **전개 (런 반복):** 스테이지 보스를 칠 때마다 짧은 컷 1장으로 떡밥을 하나씩 공개 (저택 주인의 정체, 공허의 원인).
3. **결말 (최종 보스):** 반전은 가볍게 (E). 엔딩 컷 3~5장 + 무한 모드 해금.

### 7-2. 서사 전달 수단 (가벼운 게임에 맞는 것만)
| 수단 | 분량 | 위치 |
|---|---|---|
| 전투 시작 한 줄 대사 | 1줄 | 배치 → 전투 전환 시 말풍선 |
| 방 클리어 리액션 | 1줄, 캐릭터별 랜덤 | 갈림길 화면 |
| 유물 플레이버 텍스트 | 1줄 | 유물 툴팁 아래 회색 글씨 |
| 캐릭터 프로필 | 3줄 (좋아하는 것, 싫어하는 것, 한마디) | 캐릭터 쇼룸 정보 패널 |
| 보스 등장 컷인 | 1장 + 이름 + 별명 | 보스 웨이브 시작 |
| 전멸·퇴근 컷인 | 1장 + 1줄 | 게임오버 화면 |

### 7-3. 하지 않을 것
- 전투 중 대화창으로 진행 끊기
- 고유명사 남발 (지명·세력 이름은 5개 이하)
- 캐릭터 사망·비극 서사
