# 로비 리뉴얼: 캐릭터 없는 PC 게임 화면 시안 2종

## 최종 요청

2026-11-11 사용자가 초기 캐릭터 포함 UI를 유치하다고 지적하고, 서 있는 캐릭터 없이 최근 스팀 게임처럼 감각적인 방향의 두 가지를 다시 요청. 따라서 이전의 3종 제작 방향을 이 2종으로 대체했다.

## 실제 로비 조사

- `project.godot`: 메인 씬은 `scenes/Lobby.tscn`, 디자인 해상도 1920×1080.
- `scripts/lobby.gd`: SceneSwitcher.SCENES에서 모드 카드를 구성. 모드 선택, 입장, 게임 종료, 숫자키와 F11 안내. 현재 시각 구조는 보라 그라데이션, 왼쪽 카드, 오른쪽 기존 스탠딩.
- `scripts/scene_switcher.gd`: 현재 모드는 메인전투 / 터치 게임 · 캐릭터 선택 / VOID DEFENSE (원화 조립 테스트) / 연출 연구실 / VFX 쇼룸. 설정 버튼과 메뉴 제공.
- `docs/ui_intro/lobby_1800.png`: 기존 로비의 실제 캡처로 시각 구조 확인. 캡처의 일부 메뉴명/순서는 과거 상태이므로 최신 목록은 코드를 우선.
- `docs/캐릭터_쇼룸_UI_결정사항.md`와 실제 전투 화면을 확인했으나, 최종 사용자의 성숙한 방향 변경 지시에 따라 두꺼운 라벤더 프레임과 캐릭터를 새 시안에서 제외.

## 반영한 정보 구조

| 코드의 실제 항목 | 화면 표기 |
|---|---|
| 메인전투 | 메인전투 / VOID DEFENSE / 입장 |
| 터치 게임 · 캐릭터 선택 | 터치 게임 · 캐릭터 선택 |
| VOID DEFENSE (원화 조립 테스트) | 원화 조립 테스트 |
| 연출 연구실 | 연출 연구실 |
| VFX 쇼룸 | VFX 쇼룸 |
| 설정 메뉴 | 설정 |
| 종료 | 게임 종료 |

- 재화, 상점, 가챠, 퀘스트 등 현 로비에 없는 기능을 추가하지 않음.
- 화면의 `심야 상담소`는 네러티브에 맞춘 시각적 부제 제안.

## 산출물

- `01_cinematic_lobby.png`: 비스듬한 접수 공간, 왼쪽 타이포그래피 메뉴. 공간의 몰입과 여백 중심. 선택 항목의 얇은 분홍 선으로 강조.
- `02_command_deck_lobby.png`: 기억 작업대와 상담 칸, 하단 가로 모드 내비게이션과 선택 모드/입장 영역. 이미지와 조작 영역을 명확히 구분.
- 두 시안 모두 내장 image_gen 사용. 실제 게임을 변경하거나 구현 후 캡처한 것이 아니라, 게임 화면처럼 구성한 리뉴얼 컨셉 이미지.
- 전체 생성 프롬프트: `prompt_01.txt`, `prompt_02.txt`.

## 웹 확인과 디자인 해석

- [ROUTINE 공식 Steam 페이지](https://store.steampowered.com/app/606160/ROUTINE/): 2025-12-04 출시 표기와 공식 소개의 공간 몰입·최소 UI 방향 확인.
- [Citizen Sleeper 2 공식 Steam 페이지](https://store.steampowered.com/app/2442460/Citizen_Sleeper_2_Starward_Vector/): 2025-01-31 출시 표기, 내러티브 중심 SF·사이버펑크 및 공식 아트 참여 소개 확인.
- 위 페이지의 현재 공식 소개를 참고한 자체 디자인 해석이다. 특정 게임의 메뉴를 복제하거나 이 두 작품이 모든 최신 Steam 게임을 대표한다고 간주하지 않음. 웹에 연결된 일부 이미지 파일을 가져오지 못했으므로 그 이미지를 시각적으로 분석했다는 주장은 하지 않는다.
- 이미지 생성의 실제 시각 입력은 이 프로젝트의 `docs/lobby_concept_memory_dispatch/lobby_memory_dispatch_v1.png` 한 장이며 색감과 분위기만 참고.

## 시각 검수

- 선택된 두 원화에서 사람과 캐릭터, 두꺼운 둥근 장식 프레임 없음.
- 5개 모드, 설정·종료, 입장 동작과 단축키 안내를 모두 읽을 수 있음을 확인.
- 주요 메뉴가 프레임 밖으로 잘리지 않고, 배경과 텍스트 명암이 분리됨.
- 검푸른 공간, 청색 모니터, 제한된 분홍 강조색 유지. 두 시안의 메뉴 배치가 왼쪽 세로/하단 가로로 구분됨.
- 실제 키보드 조작, 화면비 확장, 클릭 영역과 게임 내 가독성은 아직 검증하지 않은 컨셉 단계.
- 게임 코드·씬·런타임 에셋·빌드 변경 없음.
