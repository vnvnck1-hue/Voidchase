# 새 드로잉에 사용한 프롬프트

내장 image_gen으로 생성. 선택된 출력은 `exec-eeac48da-05c2-4462-8d86-fea00831516c.png`이며 프로젝트에 `silver_twintail_pink_hoodie_v3.png`로 복사했다. 입력1~4는 최초 원화 네 장, 입력5는 외형 원화와 비례 가이드의 결합 참고 시트. 이전 생성본이나 가로/세로 변형 수치에 대한 편집 지시를 사용하지 않았다.

새로운 전신 캐릭터 원화를 처음부터 그린다. 이전 생성 그림은 입력하지 않았으며, 이전 그림을 누르거나 늘리는 보정 작업이 아니다.

입력 1~4: 이 게임의 실제 최초 캐릭터 원화 네 장. 같은 사람이 같은 게임의 다섯 번째 캐릭터를 그린 것처럼 얼굴 구성, 몸통 덩어리, 팔다리 형태, 굵은 검정 선과 단순한 셀 명암을 그대로 따른다.
입력 5: 왼쪽은 최초 네 장에서 분석한 인체 배치 가이드, 오른쪽은 외형 디자인 참고. 오른쪽의 사실적 신체 비례와 입체 채색은 사용하지 않는다. 최종 출력에는 가이드나 글자를 넣지 않는다.

새 캐릭터: 은회색 긴 양갈래, 짧은 앞머리, 황금빛 연두 눈, 반쯤 감긴 눈과 무심한 작은 입. 어깨 양쪽에 트임이 있는 분홍 크롭 후드, 크림색 후드끈, 단추 두 개가 있는 흰 하이웨이스트 플리츠 치마바지, 흰 스캘럽 장식이 있는 분홍 긴 양말, 흰색·분홍색 캐주얼 신발. 로고/문구는 없다.

핵심은 최초 원화와 같은 자연스러운 SD 인체를 새로 설계하는 것이다. 머리는 주 머리 정수리~턱을 한 단위 H로 할 때 전신이 약 2.7H. 머리 1H, 턱 아래부터 가랑이까지 약0.85H, 가랑이부터 신발바닥까지 약0.87H의 공간에 형태를 처음부터 배치한다. 따라서 작은 몸통과 단순한 하체가 큰 머리를 받친다. 머리카락 양갈래 길이를 머리 높이에 포함하지 않는다.
얼굴·눈·두개부는 정상적인 카툰 형태로 그린다. 눈동자는 온전한 타원, 턱은 최초 원화처럼 기울어진 부드러운 면, 의상 주름은 자세와 중력에 맞춘 새 주름. 완성 그림을 축방향으로 변형한 듯한 납작한 눈, 옆으로 찌그러진 신발과 손, 눌린 상체를 만들지 않는다. 키 큰 패션 일러스트나 장신 애니메이션 인체도 아니다.

새 스탠딩 포즈: 고개는 살짝 화면 왼쪽으로 향하고, 한 손은 허리에, 다른 손은 허벅지 옆으로 자연스럽게 내린다. 한쪽 다리에 체중을 두고 반대쪽 발끝은 약간 밖으로. 팔꿈치와 손은 허리 실루엣과 겹치지 않게 간격을 둔다. 양갈래는 새로 비대칭으로 설계해 한쪽은 어깨 뒤로, 다른 쪽은 옆으로 흐르게 하며 머리 주변 여백을 만든다.
몸통·골반·무릎이 연결되는 선을 먼저 잡고, 그 자세에 맞는 후드 소매, 치마 주름, 신발 원근을 새로 그린다.

그림체는 입력1~4의 굵은 검정 외곽선, 제한된 내부선, 큰 색면, 1~2단계의 넓고 경계가 뚜렷한 셀 그림자, 작은 단순 하이라이트. 미세한 머리카락 묘사, 그라데이션, 광택 피부, 3D 조명, 사실적인 가슴/허벅지/입술은 없다. 한 인물의 머리와 양발이 전부 보이는 완성 전신 원화. 흰 배경, 세로 구도, 충분한 여백. 이미지 안에 설명, 치수, 비교표, 하트 이펙트, 테두리, 워터마크를 넣지 않는다.
