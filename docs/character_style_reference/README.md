## 공통 그림체 해석

아래는 제작에 사용할 시각적 해석이다. 문장과 원화가 다르게 느껴지면 원화를 우선한다.

- **비례와 형태:** 머리와 머리카락의 비중이 큰 SD 카툰 비례. 작은 몸통, 단순하고 과장된 팔다리, 큼직한 손발. 일반적인 장신 애니메이션 인체 비례로 바꾸지 않는다. 정확한 등신은 네 장의 개별 차이를 인정한다.
- **선:** 굵고 선명한 검정 또는 거의 검정인 외곽선을 바탕으로, 한 획 안에서도 필압에 따른 굵기·강약 변화와 자연스럽게 가늘어지는 끝을 살린다. 내부선은 필요한 곳에만 가볍게 배치하며 선의 가장자리에는 손으로 그린 미세한 붓결을 남긴다. 둥근 곡선과 뾰족하게 꺾이는 머리끝·의상 형태가 함께 만드는 리듬을 유지한다. 모든 선을 같은 굵기와 매끈함으로 처리하지 않는다.
- **얼굴:** 얼굴에서 큰 비중을 차지하는 눈, 두꺼운 윗눈꺼풀·속눈썹, 단순한 코와 입. 눈꺼풀 각도, 홍채, 눈썹, 입 모양으로 성격과 감정을 뚜렷하게 구분한다. 반쯤 감긴 눈과 크게 열린 눈 모두 이 화풍의 범위다.
- **머리카락과 실루엣:** 머리카락을 큰 덩어리로 나누고 끝의 방향과 볼륨으로 개성을 만든다. 잔머리나 가는 모발 묘사를 과하게 늘리지 않는다. 작은 크기에서도 인물과 포즈가 읽혀야 한다.
- **색과 명암:** 구분이 분명한 면색, 적은 단계의 넓은 셀 명암, 선택적인 간단한 하이라이트. 따뜻한 피부색과 분홍 볼, 보라·남색 계열의 어두운 색을 참고하되 캐릭터마다 고유 팔레트를 허용한다. 사실적인 재질·입체광·복잡한 그라데이션이 지배하지 않게 한다.
- **밀도와 질감:** 장식과 옷 주름은 큰 형태를 해치지 않는 수준으로 단순화한다. 손그림 선의 강약과 질감은 공통 제작 기준으로 유지하되, 거칠기와 미세 입자감의 정도는 네 원화의 차이를 인정한다. 모든 캐릭터에 동일한 노이즈나 거친 브러시 질감을 기계적으로 입히지 않는다.

## 선화: 손그림 강약과 질감

2026-11-10 사용자 추가 지시: 최초 기준 원화처럼 선에 강약과 손그림 질감을 살린다. 지나치게 일률적인 선은 사용자가 원치 않는 AI 같은 인상을 주므로 지양한다.

- **필압과 굵기 변화:** 외곽선과 내부선을 두 가지 고정 굵기로 나누는 데 그치지 않는다. 같은 획에서도 힘을 싣고 빼는 변화가 느껴지게 하며, 머리끝·주름선 등의 시작과 끝은 형태에 맞게 자연스럽게 가늘어진다. 겹침과 형태의 무게를 강조하는 부분은 두껍게, 가벼운 세부선은 얇게 처리한다. 변화는 형태의 흐름을 따르며 임의로 들쭉날쭉하게 만들지 않는다.
- **선 자체의 질감:** 선의 가장자리에 미세한 불규칙성과 붓결, 약한 잉크 농도 차이를 남겨 직접 그린 인상을 유지한다. 확대했을 때 질감이 보이면서 게임 표시 크기에서는 실루엣과 표정이 또렷해야 한다. 질감의 강도는 최초 네 장을 직접 비교해 정한다.
- **지양할 처리:** 전 구간이 같은 굵기인 선, 모든 윤곽을 완벽하게 매끈한 벡터 곡선으로 정리하는 처리, 과도한 선 보정으로 필압과 붓결을 지우는 처리를 피한다. 손그림 느낌을 내기 위해 선을 무작위로 떨게 하거나, 저해상도 계단·번짐·과한 스케치선을 추가하지 않는다. 화면 전체의 노이즈 필터는 선 자체의 강약과 질감을 대신할 수 없다.
- **생성·편집 지시:** 향후 캐릭터 프롬프트에 굵은 검정 외곽선뿐 아니라 ‘필압에 따른 굵기 변화, 자연스럽게 가늘어지는 획 끝, 미세한 브러시 가장자리 질감, 최초 네 장 수준의 정돈된 손그림 선화’를 명시한다. ‘깨끗한 선화’나 ‘고화질’ 요구가 이 특성을 지우는 매끈한 균일선으로 해석되지 않게 한다.

선화 검수는 다음 항목을 최초 네 장과 나란히 비교한다.

- [ ] 한 획 안의 굵기 변화와 획 끝의 힘 빠짐이 자연스러운가?
- [ ] 외곽·겹침·얼굴·내부선의 강약이 형태에 맞게 구분되는가?
- [ ] 확대했을 때 선 가장자리의 미세한 붓결이 살아 있고, 모든 선이 기계적으로 균일하지 않은가?
- [ ] 실제 게임 표시 크기에서 실루엣과 표정이 선명하며, 질감이 지저분한 떨림이나 픽셀 깨짐으로 보이지 않는가?

## 적용과 우선순위

- 향후 캐릭터 신규 제작, 리디자인, 표정·포즈 변형, 스탠딩·카드 초상 제작 및 검수에 적용한다.
- 이후 사용자의 명시적인 변경 지시 → 이 네 장의 원화 → 이 문서의 해석 → 이전 캐릭터 컨셉·스타일 프롬프트 순서로 우선한다. 기존 프롬프트는 당시 작업 기록으로 남기며 현재 기준을 덮어쓰지 않는다.
- 메이드복, 특정 머리색, 한쪽 눈 가리기, 리본, 별 모양 하이라이트는 개별 디자인 요소다. 모든 캐릭터가 같은 의상·표정·특징을 가져야 한다는 뜻은 아니다.
- 2026-11-10 사용자 교정: 외부 원화를 우리 캐릭터로 재해석할 때는 머리·의상·색 등의 외형 디자인만 가져온다. 신체 비례, 몸통과 팔다리의 형태, 얼굴 구성과 전체 캐릭터의 폼은 반드시 우리 네 장에 맞춰 다시 구성한다. 외부 원화의 구도·포즈·입체적인 신체 묘사는 별도 요청 없이 유지 조건으로 넣지 않는다.
- 이미지 생성·편집 시 가능한 경우 이 네 장을 실제 시각 레퍼런스로 제공하고, 그림체 참고와 새 캐릭터의 외형·의상·포즈 요구를 구분해 전달한다. 설명문만으로 대체하지 않는다.
- 검수 시 얼굴과 눈의 표현, 머리 대비 신체 비례, 외곽선의 무게와 필압 변화·붓결, 머리카락 덩어리, 명암의 단순성, 축소했을 때의 가독성을 네 장과 직접 비교한다. 선화는 위의 손그림 강약·질감 검수 항목도 함께 확인한다.
- 등신대 교정: ‘큰 머리·작은 몸통’이라는 설명을 과장해 일반적인 유아형 SD로 바꾸지 않는다. 프롬프트에 임의의 머리 높이 비율(예: 전체 높이의 40~45%)을 고정하지 않는다. 머리카락·장식의 외곽과 실제 두개부 높이를 구분하고, 동일한 전신 높이에서 턱·어깨·허리·골반·무릎·발 위치와 폭을 기준 원화와 함께 비교한다. 이전 생성물의 비례를 기준 원화 대신 재사용하지 않는다.
- **사용자 지정 비례 고정:** 등신대 분석과 검수는 [`proportions/README.md`](proportions/README.md)를 따른다. 주 머리 정수리~턱을 H로 한 수동 투영 측정에서 최초 네 장의 정수리~발바닥은 약 **2.67~2.80H**, 제작 목표는 **2.72H**다. 이 측정 정의와 다른 일반적인 등신 수치를 혼용하지 않으며, 범위 밖 생성물을 확정본으로 내지 않는다. 관절 위치의 가림·포즈 차이에 따른 불확실성은 별도 기록한다.
- 이번 지정의 범위는 **캐릭터 그림체**다. 배경·UI의 기존 개별 지침은 별도 변경 요청이 있을 때 조정한다. 기존 게임 에셋의 교체는 개별 제작·수정 작업에서 진행한다.
