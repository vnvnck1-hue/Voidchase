# 최초 원화 비례 분석 및 검수 규격

2026-11-10 사용자 지시: 최초 기준들의 등신대를 면밀하게 분석해 그대로 맞추고 그 규격을 벗어나지 않을 것.

동일 날짜 사용자 승인: 분홍 양갈래 v3와 측정 비교표를 확인한 뒤 “좋아. 앞으로 이렇게 작업해줘.”라고 지시함. 이후 캐릭터 제작에서도 **원화 분석 → 비례 가이드 → 제작 → 같은 H로 측정·비교 → 범위 밖 결과 보정 → 산출물과 근거 보관**을 기본 작업 방식으로 유지한다. 분홍 양갈래 v3는 승인된 진행 사례이며 최초 네 장의 기준을 대체하지 않는다.

후속 교정: 사용자가 은회색 양갈래 v2의 결과를 “위아래를 찌그러뜨린 것 같다”고 지적했다. 비율 수치만 맞추기 위한 가로/세로 변형 지시를 반복하지 않는다. 이전 그림의 구조가 부자연스러우면 최초 원화로 돌아가 인체와 옷의 형태를 새로 설계한다. 머리카락 외곽 폭은 얼굴·두개부 폭과 다르므로, 헤어스타일에 따른 투영 단면 차이를 인체 압축/확대로 해결하지 않는다. 측정은 큰 비례 오류를 찾는 보조 수단이며, 눈·턱·목과 어깨·팔다리·주름·신발 원근의 자연스러움도 함께 확인한다.

## 측정 정의

- **H**: 이미지에 보이는 **주 머리덩어리의 정수리에서 턱까지의 수직 높이**. 모자·머리띠·독립 양갈래·삐친 머리는 제외한다. 가려진 실제 두개골을 복원해 잰 해부학적 등신이 아닌, 동일한 시각적 기준으로 비교하기 위한 투영 비례다.
- **전신 비례**: `(발바닥 y - 주 머리 정수리 y) / H`. 전체 캔버스 높이나 장식까지 포함한 알파 바운딩 박스를 H와 혼용하지 않는다.
- 모두 사람이 원화를 보며 표시한 픽셀 좌표다. 윤곽선 두께·머리 기울기 때문에 경계 선택에 오차가 있고, 옷에 가려진 어깨·허리·골반·무릎은 추정이다. 수치의 소수점은 계산 결과이며 원화가 그 정밀도로 제작되었다는 뜻이 아니다.
- 앞서 대화에서 말한 ‘약 3등신/4등신’과 프롬프트의 ‘머리 40~45%’는 측정 전의 추정이며 현재 규격으로 사용하지 않는다.

## 원본 좌표와 전신 비례

| 원화 | 원본 크기 | 주 머리 정수리 y | 턱 y | H(px) | 발바닥 y | 전신/H |
|---|---|---:|---:|---:|---:|---:|
| 그룹 22 | 1386×1744 | 200 | 747 | 547 | 1730 | 2.80 |
| 그룹 30 | 1256×1754 | 145 | 745 | 600 | 1750 | 2.67 |
| 그룹 32 | 1271×1845 | 155 | 780 | 625 | 1835 | 2.69 |
| 레이어 193 | 1139×1632 | 8 | 600 | 592 | 1622 | 2.73 |
| 분홍 양갈래 v3 | 1009×1558 | 120 | 655 | 535 | 1552 | **2.68** |

최초 네 장의 관찰 범위는 반올림하면 **2.67~2.80H**, 중앙 제작 목표는 **2.72H**다. 새 원화의 판단에는 같은 좌표 선택 방법을 사용한다. 신규 캐릭터의 머리를 상대적으로 줄여 몸을 길게 만드는 보정은 금지한다.

## 몸통·사지 관계

정수리를 0, 턱을 1로 놓은 좌표. 관절이 가려지고 포즈가 다른 네 장을 완전히 동일한 뼈대로 간주하지 않는다. 아래 범위를 고정 단일 값으로 강제하거나 원화 중 하나만 유일한 기준으로 삼지 않는다.

| 지점 | 네 장의 대략적 범위(H) | 제작 가이드(H) | v3 측정/추정(H) |
|---|---:|---:|---:|
| 턱 | 1.00 | 1.00 | 1.00 |
| 어깨 | 1.07~1.09 | 1.09 | 1.10 |
| 허리 | 1.27~1.48 | 1.43 | 1.43 |
| 가랑이 | 1.70~1.97 | 1.85 | 1.74 |
| 무릎 | 2.09~2.36 | 2.26 | 2.04 |
| 발바닥 | 2.67~2.80 | 2.72 | 2.68 |

v3는 전신/H가 원화 범위 안이며, 몸통·골반도 관찰 범위에 들어온다. 무릎은 굽힌 포즈와 단순화된 윤곽 때문에 판독이 불명확하며 추정치는 원화의 하한보다 약 0.05H 위에 있다. 따라서 모든 관절이 픽셀 단위로 동일하다고 표현하지 않는다. 무릎의 높이까지 완전히 고정해야 하는 납품에는 관절이 명확한 공통 정면 포즈를 따로 제작해야 한다.

## 이후 작업 규칙

1. 최초 네 장을 실제 이미지 레퍼런스로 제공한다. 외부 캐릭터와 이전 생성물은 의상·머리 디자인 참고에만 사용한다.
2. 장식을 제외한 주 머리 정수리와 턱을 표시하고 H를 계산한다. 새 캐릭터도 같은 방식으로 측정한다.
3. 최초 원화의 전신/H 범위 **2.67~2.80H**에서 벗어난 결과를 확정본으로 내지 않는다. 중앙 목표 2.72H를 사용한다.
4. 전신/H만 통과시키지 말고 몸통·골반·사지의 상대 위치와 폭도 겹쳐 보며 확인한다. 기울기와 가려진 관절의 불확실성은 기록한다.
5. 디테일 밀도나 의상을 바꿀 때 비례까지 바꾸지 않는다. 범위 밖 결과는 이미지 생성 도구로 수정하고 다시 측정한다.
