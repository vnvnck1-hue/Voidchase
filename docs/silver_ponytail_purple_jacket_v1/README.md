## 디자인 정리

한쪽 눈을 가리는 큰 백은색 앞머리, 각지게 꺾이는 머리끝, 어두운 머리끈과 흰 주름 장식으로 묶인 낮은 포니테일, 보이는 금색 눈과 보라 눈꺼풀, 심술난 작은 입을 유지했다.

큰 보라색 퍼프 재킷과 흰 파이핑, 은색 지퍼, 검정 이너와 흰 주름 칼라, 금색 마름모 펜던트, 흰 플리츠 스커트, 짙은 자두색 긴 양말, 핑거리스 장갑과 흰 십자 잠금 장식을 재구성했다. 잘린 머리 위와 양발을 완성하고, 흰색/연보라색 부츠는 원본에서 확인되는 색과 커프 디자인을 연결해 해석했다. 주변의 잘린 다른 인물 조각은 제외했다.

최초 원화 네 장을 실제 입력으로 제공했다. 그룹30은 한쪽 눈과 반쯤 감긴 눈꺼풀, 짧은 몸통과 전신 균형을 구체적으로 참고했고 다른 최초 원화도 형태와 선/명암 기준으로 함께 사용했다. 손을 가슴 앞에서 재킷에 댄 새로운 안정적인 전신 자세로 소매·장갑·의상 접힘을 구성했다. 보이는 눈은 프로젝트의 큰 카툰 눈으로 재해석했다.

하체 완성 과정에서는 상체 그림을 같은 크기로 두고 빈 하체 영역에 기하학적인 관절 배치 가이드를 만든 다음 image_gen으로 다리와 부츠를 새로 그렸다. 이 가이드는 최종 원화가 아니며 모든 선/문구는 최종 결과에서 제거되었다.

## 수동 비례 검수

`../character_style_reference/proportions/README.md`의 H 정의를 사용한다. **주 머리덩어리의 정수리 y60**을 선택하며, 독립적으로 위로 솟은 뾰족한 머리끝과 포니테일은 H에서 제외한다. 턱 외곽은 확대 판독했다.

| 지점 | y(px) | 정수리 기준 H |
|---|---:|---:|
| 주 머리 정수리 | 60 | 0.00 |
| 턱 외곽 | 585 | 1.00 |
| 어깨(추정) | 632 | 1.09 |
| 허리(추정) | 835 | 1.48 |
| 가랑이(추정) | 990 | 1.77 |
| 무릎(추정) | 1160 | 2.10 |
| 발바닥 | 1476 | **2.70** |

H525px, `(1476-60)/525 = 2.697H`로 최초 원화의 관찰 범위 약2.67~2.80H 안이다. 수치는 수동 윤곽 판독이며 의상과 포즈가 가리는 관절은 추정이다. 숫자만으로 동일한 형태임을 보장하지 않고, 눈/턱의 면 구성과 목~어깨~몸통~골반 연결, 손가락과 부츠의 원근도 함께 시각 확인했다.
