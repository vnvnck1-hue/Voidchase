# 네러티브 기획서 — 「마음 정리 상담소」

작성일: 2026-11-06 · 상태: **방향 합의, 세부 미결** · 대상: VOID DEFENSE (공허 유적 자동전투 + 유물 성좌판)

> 이 문서는 지금까지 정리된 네러티브 내용을 한곳에 모은 기준 문서다.

## 1. 한 줄 요약

**마음이 어질러진 의뢰인의 마음속에 들어가, 엉킨 생각을 치우고 잃어버린 좋은 기억을 되찾아 주는 메이드 상담소 이야기.**

- 장르 톤: 가벼운 일상 개그 + 의뢰마다 작은 감동 한 스푼
- 그림 톤: 치비, 만화 효과음, 말풍선 (`assets/컨셉 원화/화면 컨셉_2`)
- 로고: **VOID DEFENSE** 유지 (부제는 미정)

---

## 2. 왜 이 방향인가

| 이유 | 설명 |
|---|---|
| 시스템이 그대로 비유가 됨 | 유물 성좌판 = 마음의 별자리, 침식 = 부정적 생각에 덮인 기억, 거점 = 마음속 가장 편한 장소 |
| 실패가 가볍다 | 분대 전멸 = "오늘 상담은 여기까지". 다음 회기 예약일 뿐이다 |
| 반복 플레이 자체가 메시지 | 로그라이트 반복 = "회복은 한 번에 되지 않는다" |
| 메이드가 자연스럽다 | 마음속도 결국 '집'. 상담소 간판은 "마음 정리 대행" |
| 콘텐츠 단위가 깔끔하다 | 의뢰인 1명 = 스테이지 1개. 업데이트 단위로 바로 쓸 수 있다 |
| 여러 후보 안을 흡수 | 청소 메이드단(A) · 별자리(B) · 공허 군주와의 화해(E)를 한 설정으로 묶는다 |

---

## 3. 소재 원칙 (반드시 지킨다)

'정신질환 치료'를 그대로 내세우면 질병을 몬스터로 만들어 부수는 구도가 되어 낙인·희화화로 읽힐 수 있다. 다음 원칙으로 가볍고 안전하게 간다.

1. **진단명을 쓰지 않는다.** 게임 안 표현은 '고민', '마음 정리'. 소재는 일상적인 것: 시험 불안, 완벽주의, 번아웃, 이별, 무대 공포, 외로움.
2. **적은 사람도 병도 아니다.** 적은 '엉킨 생각'이다. 보스(가장 큰 응어리)는 부수지 않고 **진정시킨다**. 진정되면 작아져서 그 응어리의 원래 모습이 드러난다.
3. **회복의 주체는 의뢰인이다.** 마지막 문은 분대가 아니라 의뢰인이 직접 연다.
4. **분대는 의사가 아니다.** '정리 도우미'다. 엔딩은 의뢰인이 친구·가족·전문가에게 말을 꺼내는 쪽으로 맺는다.
5. **무거운 소재는 다루지 않는다.** 자해·자살·학대 제외.
6. (검토) 게임 시작 시 안내 1줄, 설정 메뉴에 상담 기관 안내.

## 4. 세계와 시스템 매핑

| 게임 요소 | 서사 의미 |
|---|---|
| 런 1회 | 의뢰인 1명의 마음 방문 1회 (= 상담 1회기) |
| 공허 유적 | 의뢰인의 **마음 풍경**. 의뢰인마다 테마가 다르다 |
| 떠다니는 돌·보라 하늘·큰 달 | 의뢰인별로 의미를 다시 붙인다 (예: 의뢰인 01에서 큰 달 = 밤새 켜 둔 스탠드) |
| 방 전진 | 기억의 방들을 차례로 들여다보기 |
| 갈림길 | "어느 기억부터 볼까요?" |
| 공허 잔재·파편·포자·결정체 | **엉킨 생각·잡념**. 능력치는 그대로, 의뢰인별 별명과 말풍선만 붙인다 |
| 공허 군주 (보스) | 그 사람의 가장 큰 **응어리**. 처치 = 진정 → 원래 모습 공개 |
| 유물 | 의뢰인의 **좋은 기억 조각**. 기능은 그대로, 툴팁에 기억 한 줄 |
| 유물 성좌판 | **마음의 별자리**. 좋은 기억을 끼울수록 마음 하늘이 밝아진다. 방마다 +1칸 = 기억 하나 되찾기 |
| 침식 칸 | 부정적인 생각에 덮여 안 보이는 기억. 칸 위에 "부족해" 같은 글씨, 정화하면 지워진다 |
| 별 깃발 거점 | 의뢰인의 **안전 기지** (마음속 가장 편한 장소) |
| 분대 전멸 | "오늘 상담은 여기까지" → 다음 회기 |
| 공허 정수 (런 재화) | 정리하며 모은 마음 조각 (명칭 유지 여부 미정) |
| 시간의 결정 (영구 재화) | 상담소 경험 / 의뢰인과 쌓은 신뢰 |
| 처치 효과음 자막 | (검토) "BANG!" 대신 "정리!", "치웠다!" 계열 섞기 |

## 5. 등장인물

이름과 성격 세부는 아직 미정이라 역할로 적는다.

| 역할 | 외형 (현재 아트) | 위치 | 성격·말투 |
|---|---|---|---|
| **반장** | 멜빵 작업복 소녀 (`char_02`) | 전투에 나가지 않음. 좌하단 턴테이블 자리의 **해설자** | 상담소 현장 반장. 일 얘기하듯 툭툭, 그런데 핵심은 정확히 짚는다 |
| 기사 | 금발 기사 (검·방패) | 전투 분대 | 직설적이고 따뜻함. 감탄 담당 |
| 건너 | 핑크 건너 (SMG) | 전투 분대 | 눈치 빠른 관찰자. 숫자·디테일에서 숨은 사실을 찾는다 |
| 마법사 | 보라 메이드 (오브 지팡이) | 전투 분대 | 조용하고 건조한 유머 |
| 힐러 | 금발 메이드 (십자 지팡이) | 전투 분대 | 다정함. 의뢰인에게 직접 말을 거는 역할 |
| 쇼룸 나머지 캐릭터 | 쇼룸 7인 중 나머지, 올리비아 | 미정 | 상담소 직원 / 해금 캐릭터 후보 |

톤 예시:
- 반장 "자, 오늘 정리할 집은 여기예요. 신발은 벗고 들어가요."
- 힐러 "다 치우진 않아도 돼요. 걸려 넘어지지 않을 만큼만."
- 건너 "이 생각, 세 번째 방에서도 나왔어요. 끈질기네."

## 6. 전체 구조 (얇은 3막)

1. **도입 (첫 런, 1분 이내):** 상담소 문 앞의 쪽지 한 장 + 분대 자기소개 한 마디씩 → 바로 전투.
2. **전개 (의뢰인 반복):** 의뢰인마다 독립된 짧은 이야기. 의뢰가 쌓이며 상담소 쪽 떡밥을 조금씩 공개한다 (상담소는 어떻게 마음에 들어가나, 반장은 왜 이 일을 하나 등. 미정).
3. **결말:** 가벼운 반전 + 엔딩 컷 몇 장 + 무한 모드 해금. (기존 기획안의 "공허 군주 토벌 엔딩"을 대체할 방향. 세부 미정)

## 7. 의뢰인 스테이지 템플릿

새 의뢰인을 만들 때 채우는 칸.

| 항목 | 내용 |
|---|---|
| 의뢰인 프로필 | 이름 · 나이 · 직업 · 고민 한 줄 · 의뢰 경위 |
| 마음 풍경 | 테마 이름 + 배경 요소별 의미 |
| 안전 기지 | 거점 깃발 자리의 의미 |
| 엉킨 생각 | 적 type별 별명 + 등장 말풍선 2개 |
| 방 목록 | 방 6개 (기억) + 갈림길 + 보스 방, 방마다 입장 대사 1줄 |
| 좋은 기억 | 획득 유물별 기억 한 줄 |
| 침식 글씨 | 침식 칸에 뜨는 말 |
| 보스 | 이름 · 별명 · HP 75/50/25% 외침 · 진정 후 모습 |
| 마지막 문 | 의뢰인이 직접 여는 장면 대사 |
| 엔딩 | 컷 3장 (마음속 → 현실의 작은 변화 → 누군가에게 말 걸기) |
| 전멸 | 컷 1장 + 재도전 시 바뀌는 첫 대사 |
| 수집품 | 의뢰인 엽서 1장 (상담소 벽, 메타 수집) |
| 새 아트 | 초상 (표정 2종), 엔딩 컷 3장, 상징 소품 1개 |

## 8. 서사 전달 방식 (가벼운 게임에 맞는 것만)

| 수단 | 분량 | 위치 |
|---|---|---|
| 방 입장 대사 | 1줄 | 배치 → 전투 전환 시 말풍선 |
| 방 클리어 리액션 | 1줄, 캐릭터별 랜덤 | 갈림길 화면 |
| 적 등장 말풍선 | 1줄 | 적 머리 위 |
| 유물 기억 텍스트 | 1줄 | 유물 툴팁 아래 회색 글씨 |
| 캐릭터 프로필 | 3줄 (좋아하는 것, 싫어하는 것, 한마디) | 캐릭터 쇼룸 정보 패널 |
| 보스 등장 컷인 | 1장 + 이름 + 별명 | 보스 방 시작 |
| 보스 외침 | 1줄 × 3 | 상단 기믹 메시지 자리 |
| 엔딩·전멸 컷인 | 1~3장 + 1줄 | 결과 화면 |

하지 않을 것: 전투 중 대화창으로 진행 끊기, 고유명사 남발 (지명·세력 이름 5개 이하), 캐릭터 사망·비극 서사.

## 9. 첫 의뢰인 — 「왕관의 성」 (요약)

상세: `docs/네러티브_의뢰인01_왕관의_성.md`

- **의뢰인:** 윤하린 (가칭) · 18세 학생회장 · 고민은 "1등이 아니면 아무것도 아닌 것 같다" (완벽주의)
- **역할:** 첫 스테이지이자 튜토리얼. 방마다 하나씩 배운다 (배치 → 평타 → 고유 스킬 → 궁극기 → 유물 배치·침식 정화). 성좌판이 이 스테이지 안에서 4칸부터 10칸까지 다 열린다.
- **마음 풍경:** 상장·트로피로 쌓다 무너져 하늘에 뜬 성. 떠다니는 돌 = 지키지 못한 계획표 조각, 큰 달 = 밤새 켜 둔 스탠드, 거점 = 동아리방의 낡은 소파.
- **엉킨 생각:** 「해야 하는데…」(잔재), 「조급함」(파편), 「수군거림」(포자), 「완벽한 계획표」(결정체)
- **방:** 성문 → 새벽 4시의 책상 → 게시판 앞 복도 → 텅 빈 동아리방 → 갈림길 (축제 무대 뒤 / 혼자 남은 교실) → 왕좌의 방 앞 계단 → 왕좌의 방
- **좋은 기억 (1차 유물 5종):** 뇌운 조각 = 축제 회의에서 인정받은 순간, 잉걸불 = 첫 합주의 열기, 서리 결정 = 시험 끝나고 눈 맞으며 먹은 아이스크림, 공허 정수병 = 동아리 롤링페이퍼, 별 깃털 = 꼴찌로 들어온 운동회 날 아빠의 "끝까지 뛰었네" (보스 방 직전 확정 지급, 위기 보호막)
- **보스 「1등의 왕관」:** "2등은 꼴찌랑 똑같아". 진정되면 유치원 때 만든 종이 왕관이 된다. 마지막 문은 하린이 직접 연다.
- **엔딩:** 종이 왕관을 소파에 내려놓음 → 계획표에 「토요일 — 합주」 → 친구에게 "떡볶이 먹을래?"
- **전멸:** "오늘 상담은 여기까지!" 다시 도전하면 하린의 첫 대사가 "…또 와 주셨네요."로 바뀐다.
- **새 아트:** 하린 초상 2종, 엔딩 컷 3장, 전멸 컷 1장, 종이 왕관, 엽서. 나머지는 기존 에셋 재사용.

## 10. 검토했던 다른 안 (보류)

| 안 | 요약 | 흡수 여부 |
|---|---|---|
| A. 공허 청소 대행 메이드단 | 하늘 저택의 공허 먼지를 치우는 메이드 업체 | **흡수**: 메이드·'정리 대행' 톤 |
| B. 떨어진 별자리 줍기 | 공허에 떨어진 별을 주워 별자리를 꿰맴 | **흡수**: 성좌판 = 마음의 별자리 |
| C. 낮잠 원정대 | 꿈속 악몽 방어, 보스 = 그날의 걱정 | 보류 (F와 구조가 겹침) |
| D. 공허 유적 생중계 | 방송 4인조의 탐사 방송, 갈림길 = 시청자 투표 | 보류 |
| E. 공허 군주는 친구가 없다 | 처치 대신 화해하는 엔딩 | **흡수**: 보스 진정 → 원래 모습 공개 |

## 11. 미결 사항

1. 분대 4인 + 반장 + 쇼룸 캐릭터의 **이름과 한 줄 성격**
2. 상담소 설정: 분대가 마음에 들어가는 방법 (첫 의뢰에서는 설명 없이 "신발 벗고 들어가요" 한 줄로 넘기는 안 추천)
3. 부제·로고 문구 (VOID DEFENSE 유지, 부제 교체 여부)
4. 재화 이름 (공허 정수 / 시간의 결정)을 상담소 톤으로 바꿀지
5. 효과음 자막 "BANG!" → "정리!" 계열 교체 여부
6. 의뢰인 엽서 수집을 메타 진행(도감)으로 쓸지
7. 전체 결말 (상담소 쪽 떡밥과 최종 반전)
8. 첫 의뢰인 세부: 하린의 이름·나이 확정 (사회초년생 버전 「신입 사원의 왕관」도 가능)
9. 두 번째 이후 의뢰인 목록
