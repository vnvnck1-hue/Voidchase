- 해커: 보라 포니테일·졸린 눈, 테크 후드·홀로그램 데이터 패드. 지팡이 제거.
- 메딕: 금발·분홍 눈, 민트 의료 통신기·진단 인젝터·의료 드론. 성직자 장식 제거. 작은 드론은 진단기 옆에 겹쳐 보여 독립 실루엣이 약하다.
- 가드: 금발·푸른 눈, 경량 외골격·뷰포트 방패·충격 블레이드. 중세 방패 문양·망토 제거.

## 검수 근거

최초 기준 원화 네 장과 비례 README를 확인하고 기존 construction_guide.png의 2.72H를 제작 가이드로 사용했다. 신체를 눌러 맞추지 않고 다시 그렸다. 최초 네 장은 외형 복제 대상이 아니라 동일하게 중요한 그림체·비례 기준으로 입력했다.

[동일 H 비교표](reference_comparison.png), [수동 측정 좌표와 폭 기록](landmarks.json), [확대 검수 이미지](field_detail_audit_final.png)를 보관한다. 정수리·턱·발바닥 수동 투영값은 건너 약 2.74H, 해커 2.75H, 메딕 2.70H, 가드 2.75H. 주 머리 폭은 각각 약 1.38H, 1.30H, 1.29H, 1.37H로 최초 네 장의 약 1.25~1.48H 안이다. 작은 화면의 수동 경계 판독이므로 약 ±2~3px의 불확실성이 있으며 관절 위치를 정밀 검증한 스프라이트 납품으로 간주하지 않는다.

얼굴/어깨/골반/한쪽 다리 폭도 별도 기록했다. 소매·후드·갑옷·방패 외곽과 가려진 신체 추정 폭을 구분했다. 눈·뺨·턱과 짧은 몸통, 큼직한 장갑·부츠의 형태를 원화 네 장과 같은 H로 비교했다. 허리·골반·무릎은 의상과 자세에 따른 추정이며 모든 관절이 원본의 범위에 정밀 일치한다고 주장하지 않는다. 메딕의 턱~허리 길이와 가드의 골반은 의상에 일부 가려진다.

필드에서 손잡이와 손·팔의 연결, 네 인물의 발바닥 접지와 타일 원근, 발밑 그림자, 얼굴과 장비의 겹침을 시각 검수했다. 앞 세 명은 칸 간격을 조금 넓혀 배치되어 겹침이 줄었으며 원본 픽셀 위치를 완벽히 보존한 합성이 아니다. 보라·민트·청록 장비를 큰 면으로 구분해 기존 보라 배경에서 읽힌다. 외곽/얼굴/옷 내부선 강약과 획 끝을 비교했으며, 손그림 필압 변화가 있으나 축소 화면만으로 원화 수준의 미세 붓결을 동일하게 검증할 수는 없다.

원본 캡처 1920×1080, 결과 1672×941. 이미지 생성 전체 화면 편집 특성상 UI 글자·격자·카메라 표현에는 재해석이 있다. 실제 적용 전에는 개별 투명 원화와 파츠 리그 제작이 필요하다. 이번 변경은 docs 내 시안·캡처 도구뿐이므로 exe 내보내기 대상 변경은 없다.

## 제작 기록

내장 image_gen 사용. [최초 지시](prompt.txt), [비례 재구성 지시](prompt_v2.txt), [건너 국소 교정 지시](prompt_v3.txt). v1/v2는 내부 검수 이력이며 전달 원화로 선정하지 않았다. 생성 원본은 기본 generated_images 저장소에도 남겼고, 선택 원화는 프로젝트 안으로 복사했다.

[캡처 스크립트](capture.gd) / [테스트 씬](Capture.tscn) / [엔진 로그](capture_engine.log). 적 등장 후 배치 단계에서 4초 대기하고 viewport 저장. 캡처 완료를 확인했으며 인증서 접근 오류와 종료 시 기존 리소스 잔류 로그가 있어 ERROR 0건이라고 보고하지 않는다.
