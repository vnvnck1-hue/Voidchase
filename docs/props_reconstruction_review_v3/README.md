# 기존 프랍 가림 영역 복원 — 전체 검토본 v3

승인된 왼쪽 아치와 동일한 기준으로 나머지 기존 프랍 16종을 각각 작업했다. 승인된 아치를 포함해 총 17종이며, **사용자의 전체 적용 승인 후 모두 게임에 적용했다.** 기존 크기·피벗·배치 밀도·애니메이션은 유지했다.

## 검토 이미지

각 칸의 왼쪽은 원본, 오른쪽은 복원 시안이다. 확대 비교를 위해 프랍별 표시 크기를 맞췄으며 게임 화면의 배치나 밀도를 나타내는 이미지는 아니다.

## 파일

- `raw/`: 복원한 투명 PNG 17개. ImageGen 결과 원본이며, 승인된 왼쪽 아치는 기존 승인 시안을 그대로 복사했다.
- `game_size/`: 원래 PNG와 같은 캔버스 크기의 파일 17개. 승인 후 기존 `assets/void_defense_original/background/props/`의 같은 이름 PNG를 이 파일로 교체했다.
- `prompts/`: 나머지 16종에 사용한 개별 프롬프트. **ImageGen 내장 도구**를 사용했다.
- 승인된 왼쪽 아치의 프롬프트는 [이전 작업 기록](../props_cleanup_review/README_reconstruction_v2.md)에 있다.
- `manifest.json`: 파일별 크기, 알파 검사 결과, 승인 상태. 전체 approved_and_applied.
- `originals_before_apply/`: 적용 직전 원본 PNG 17개. 비교표 재생성에도 이 원본을 사용한다.
- `build_review.ps1`: 검토 자료 생성 스크립트. 이 검토 폴더에만 출력한다.

## 복원 기준

- PSD에서 가려져 무분별하게 단색/반복 픽셀로 채워진 부분은 석재 구조와 원근에 맞게 다시 그렸다.
- 아치와 기둥은 받침·연결 석재·파단부를 복원하고, 큰 바위는 누락된 면·두께·갈라짐을 이어 그렸다.
- 원래 가림 보충량이 없던 작은 파편과 깃발은 보완을 최소화했다. 파편은 넓은 면과 두께, 깃발은 봉과 받침의 접점을 정리했다.
- 기존 보라색 계열과 단순한 면 묘사를 기준으로 했다. 생성 결과이므로 원본과 완전히 동일한 색상/형태는 아니며 위 비교표로 검토한다.
- 새 대형 프랍이나 게임 내 개수·배치 변경은 이번 승인 시안에 포함하지 않았다.

## 확인

- 원본 17종에 대응하는 복원 PNG 및 기존 캔버스 크기의 파일이 모두 있다.
- 17종 투명 배경을 확인했으며, 출력 크기 검사에 실패한 항목은 없다.
- 기존 프랍 PNG 17개만 교체하고 조립 씬·배치 스크립트·임포터 설정은 유지했다.
- Windows Desktop 내보내기 성공, 오류 0건. 변경된 17종의 임포트 매핑과 텍스처가 팩에 포함되었음을 확인했다.
- 전장 실행 및 스크린샷 확인 완료: `in_game/shot_01_t2.00.png`. 배포용 실행 파일의 기본 시작도 종료 코드 0, 오류 0건으로 확인했다.
- 빌드: `build/windows/KSC_Touch_Game.exe`. 갱신된 게임을 다시 실행했다.
- 로그: `export_stdout.log`, `capture_stdout.log`, `exe_smoke.log`.
