## 원화 유지 방식

원화의 해당 부분을 직접 크롭해 내장 image_gen 편집 모드에 입력했다. 원화의 민트·아이보리 바닥, 청록 기계부, 호박색 조명, 밝은 녹색 식물, 어두운 외곽선과 간결한 명암을 기준으로 삼았다.

배양기는 원통 배양부와 오른쪽 제어기, 재배대는 조명과 화분 두 개, 냉장 박스는 아이보리 뚜껑과 전면 눈송이 표식을 유지하도록 편집했다. 큰 온실 아치·바닥·UI·인물은 에셋에서 제외했다. 블록은 원화의 세 표면 디자인을 독립된 한 칸 모듈로 완성하고, 첫 블록을 나머지 두 블록의 실제 형태 기준으로 입력했다. 같은 크롭·균일 배율을 사용했으며 가로/세로를 따로 변형하지 않았다.

이 작업은 원화 기반 분리·보완 생성이다. 원화 픽셀을 그대로 잘라낸 무손실 추출본은 아니며, 독립 블록의 가려진 측면과 프랍의 작은 가림은 재구성했다. 마스터의 추가 표면 디테일과 형태 차이는 실제 게임 배율에서 원화의 큰 덩어리·색·구성이 이어지는지 시각 검수했다.

## 배치 기준

블록의 공통 기준점은 PNG 좌상단 기준 `(144, 76)`, **윗면 중심**이다. PNG 하단 중심으로 놓으면 유닛 좌표와 높이가 어긋나므로 이 점을 맵 칸 중심에 맞춘다. 도형 모서리와 이동 벡터는 JSON의 `top_quad_px`, `tile_step_x`, `tile_step_y`에 기록했다. 이 좌표는 시각 판독한 시작 가이드이며 충돌 형태나 엄밀한 픽셀 경계 측정값이 아니다.

프랍의 기준점은 일차 배치용 하단 중앙이다. 실제 정렬은 프랍 접지점과 기존 보드 원근에 맞춰 조정한다. 프랍 크기는 블록 윗면 폭 약 256px 기준으로, 배양기/재배대는 약 1.4칸 폭, 냉장 박스는 약 0.7칸 폭이다.

투명 PNG는 RGBA이며 배경이 없다. 도구 출력의 거의 불투명한 내부 알파(250~255)를 255로, 8 미만의 미세 잔류 알파를 0으로 정리했다. 나머지 가장자리 알파는 유지했다. 색 보정은 하지 않았고, 게임용 PNG는 고품질 균일 축소본이다. 선형 필터·무손실 PNG·밉맵 끄기·반복 끄기를 권장한다.

## 검수 및 범위

- 여섯 PNG 모두 투명 영역·불투명 내부·부드러운 가장자리 알파를 확인.
- 같은 블록 캔버스와 동일 균일 배율, 완전한 외곽 및 작은 여백 확인.
- 배경색 위 합성에서 보라색 배경/캐릭터/UI 잔류가 없는지 확인.
- 개별 PNG와 아틀라스 영역의 RGBA 일치 확인.
- 원화의 주요 부품·색과 최종 묶음 이미지를 나란히 확인.
- 캐릭터 생성/수정 없음. 신규 캐릭터 비례 검수 대상 없음.
- 이번 결과는 에셋 패키지 제작이며 게임 씬·스크립트에 연결하지 않았다. 산출물은 배포 제외 경로인 docs 아래에 보관해 기존 실행 빌드에 영향을 주지 않는다.
