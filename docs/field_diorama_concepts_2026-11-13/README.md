# 전투 필드 디오라마 컨셉 3종

작성일: 2026-11-13 (Asia/Seoul)

현재 프로젝트의 실제 전투 화면을 새로 캡처하고, 그 캡처를 직접 입력해 환경만 바꾸도록 지시한 image_gen 합성 컨셉 원화다. 런타임 배경에 적용된 결과가 아니다. 게임 코드·에셋은 변경하지 않았다.

## 원화

- [01_desert_salvage.png](01_desert_salvage.png): 사막 회수 기지 — 통신 안테나·태양전지, 회수품 상자, 배터리와 케이블, 부품 트레이, 모래와 정비 표식.
- [02_neon_data_terminal.png](02_neon_data_terminal.png): 네온 데이터 터미널 — 서버 캐비닛, 홀로그램 모니터, 케이블 릴, 저장 용기, 발광 도관과 환기구.
- [03_bio_greenhouse.png](03_bio_greenhouse.png): 바이오 온실 연구소 — 식물 배양 챔버, 온실 골조, 수경재배 모듈, 냉장 샘플 박스, 관수 배관과 뿌리 관찰창.

세 장은 각각 1672×941. 별도의 후보 이미지나 이전 생성본을 기준으로 하지 않고 모두 같은 원본 캡처에서 출발했다.

## 캡처 근거

- [battle_capture.png](battle_capture.png): 1920×1080 실제 Godot 4.7.2 Forward+ Vulkan 캡처.
- [capture.gd](capture.gd)와 [Capture.tscn](Capture.tscn): 현재 `scenes/void_defense/VoidDefense.tscn` 실행 후 적 등장 대기, `start_battle()` 호출, 2.8초 후 실제 viewport PNG 저장.
- 실행 인자: `--resolution 1920x1080 --position 80,80 res://docs/field_diorama_concepts_2026-11-13/Capture.tscn -- --vdseed=2`
- [capture_stdout.log](capture_stdout.log)에 실제 전투 씬 준비, 적 3명 생성, PNG 저장 해상도가 남아 있다.
- [capture_stderr.log](capture_stderr.log)에는 사용자 로그 경로 쓰기·인증서 저장소 접근 오류와 종료 시 리소스 잔류 경고가 있다. 렌더링과 PNG 저장은 완료되었다.

## 검수 기록

세 결과를 각각 원본 캡처와 시각 비교했다.

- 공통: 동일한 사선 시점의 떠 있는 전장, 아군 4명·적 3명의 상대 배치, 상단 웨이브/정수/체력 표시, 우측 육각 패널, 하단 네 초상 카드, 좌측 큰 캐릭터, 중앙 하단 버튼이 식별된다.
- 프랍: 키 큰 주 프랍은 후방 가장자리, 작은 프랍은 양쪽 외곽에 위치한다. 중앙 전투 공간에 큰 장애물을 추가하지 않았고 주요 캐릭터나 HUD를 가리지 않는다. 바닥 접지와 원근은 시각적으로 확인했다.
- 사막: 따뜻한 금속과 모래, 컨테이너·안테나·공구 표식·노출 케이블로 산업 기지 분위기를 형성한다.
- 데이터: 청록/자홍 포인트와 서버·그릴·바닥 회로를 반복해 현재 보라색 HUD와 연결한다.
- 온실: 민트/아이보리 바닥과 큰 잎 실루엣, 배양 기계·관수 배관으로 다른 두 안과 구분된다. 중앙의 밝은 바닥 위 유닛 실루엣은 보이지만, 실제 적용 시 흰 이름/청록 타일 표시의 대비를 조정할 여지가 있다.
- 캐릭터 기준 네 장과 관련 문서를 사전 확인했다. 신규 캐릭터나 인체 비례 변경은 지시하지 않았으며, 이번 검수는 환경 합성과 기존 캐릭터의 가시성에 대한 것이다. 신규 원화용 비례 측정을 통과했다고 주장하지 않는다.
- image_gen의 전체 화면 편집은 원본과 픽셀 단위 보존을 보장하지 않는다. 세 장은 출력 크기가 작아졌으며 UI 글자·외곽선·격자 및 플랫폼 모서리에는 재해석이 있다. 구현용 최종 에셋이 아닌 미술 방향 검토용 원화다.
