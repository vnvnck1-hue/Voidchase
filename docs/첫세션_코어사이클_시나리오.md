# 첫 세션 시나리오 — 처음 켜서 코어 사이클 한 바퀴

작성일: 2026-11-07 · 상태: **초안** · 상위 문서: `docs/네러티브_기획서.md`, `docs/네러티브_의뢰인01_왕관의_성.md`, `docs/전투_유물시스템_설계안.md`

> 목표: 유저가 exe 를 처음 켠 순간부터 **상담소 → 의뢰 → 마음 진입(런) → 방 전투 반복 → 보스 진정 → 마지막 문 → 결과 → 상담소 복귀 → 다음 의뢰 예고**까지 한 바퀴를 도는 흐름을 장면 단위로 적는다.
> 첫 의뢰인 윤하린(가칭) 「왕관의 성」이 튜토리얼을 겸한다. 목표 시간 **20~25분**.

---

## 0. 코어 사이클 정의

```
 ┌──────────── 상담소 (허브) ────────────┐
 │ 의뢰 쪽지 / 엽서 벽 / 별자리 트리 / 쇼룸 │
 └──────┬───────────────────────▲────────┘
        │ 의뢰 수락                │ 결과 (완료 = 엽서 + 결정, 중단 = 결정만)
        ▼                         │
  마음 진입 ─▶ [배치 → 전투 → 정리 연출 → 회복 → (유물 보상) → 갈림길 → 이동] ×N ─▶ 보스 진정 ─▶ 마지막 문
                       │
                       └─ 분대 전멸 → "오늘 상담은 여기까지" ─────────┘
```

- **안쪽 고리 (방 1개, 40초~1분 30초):** 배치 → 자동전투(+궁극기 탭) → 정리 연출 → 회복 → 보상 → 갈림길.
- **바깥 고리 (의뢰 1회 = 런, 12~18분):** 방 6개 + 보스. 유물 성좌판이 4칸에서 10칸까지 열린다.
- **메타 고리 (상담소):** 시간의 결정으로 영구 성장, 엽서 수집, 다음 의뢰 해금.

## 2. 장면별 시나리오

### S0. 첫 실행 · 타이틀 (0:00~0:20)
- 검정 → 큰 달이 떠오르는 보라 밤하늘 → **VOID DEFENSE** 로고 + 부제.
- 하단 "아무 곳이나 눌러 시작". 첫 실행에서는 메뉴(이어하기·설정)를 숨긴다.
- (검토 항목) 안내 1줄: "이 게임은 고민을 가볍게 다루는 판타지입니다. 실제 어려움이 있다면 가까운 상담 기관과 이야기해 보세요." 설정 메뉴에도 같은 안내.

### S1. 상담소 문 앞 · 쪽지 (0:20~0:50)
- 화면: 밤에만 문을 여는 작은 상담소 외관 (로비 컨셉 v6/v7 계열). 간판 아래 작은 글씨 "마음 정리 대행".
- 문틈에 접힌 쪽지 하나가 반짝인다 → 탭.
- 쪽지 (손글씨):
  > "제가 왜 여기 왔는지 잘 모르겠어요. 그냥, 머릿속이 너무 시끄러워요. — 윤하린"
- 문이 열리고 **반장**(멜빵 작업복, char_02)이 고개만 내민다.
  - 반장 "의뢰네요. 들어와요, 오늘 할 일 생겼어요."
- 실내 컷 1장: 분대 4인이 소파·책상에 흩어져 있다. 한 마디씩 (말풍선, 탭으로 넘김, 길게 누르면 전부 스킵).
  - 기사 "드디어 일이다!"
  - 건너 "쪽지 글씨가 엄청 반듯하네. 지우개 자국은 세 군데."
  - 마법사 "…시끄러운 머리면, 귀마개부터 챙겨야겠네요."
  - 힐러 "하린 씨, 많이 피곤하겠어요."
- 이 시점에 상담소 메뉴(엽서 벽·트리·쇼룸)는 **그림자만** 보이고 잠겨 있다. 첫 의뢰가 끝나면 열린다.

### S2. 신발 벗고 들어가요 (0:50~1:00)
- 반장 "자, 오늘 정리할 집은 여기예요. 신발은 벗고 들어가요."
- 페이크 로딩 (카드 메이드 + NOW LOADING). 첫 진입에 한해 로딩 문구를 "하린 씨 마음으로 들어가는 중…"으로.
- 전투 화면 진입: 보라 하늘, 떠 있는 성의 폐허, 큰 달. 좌상단에 장소 이름 카드가 잠깐 뜬다: **「왕관의 성」 — 윤하린의 마음**.
- 반장 해설 (좌하단 턴테이블 자리): "저 달은 하린 씨 책상 스탠드예요. 이 집은 밤이 안 끝나요."

### S3. 방 0 — 성문 · 배치 (1:00~2:30)
- 상태: PLACEMENT. HUD 는 분대 카드 4장과 "정리 시작 ▶" 버튼만. 성좌판·보관함은 어둡게 잠겨 있다.
- 튜토리얼 손가락: 영웅을 좌측 하늘색 칸으로 끌어 놓기. 4명 다 놓으면 버튼이 밝아진다.
- 적이 먼저 우측에 미리 보인다: 「해야 하는데…」(잔재) 3마리. 머리 위 말풍선 "아직 안 끝났잖아".
  - 건너 "생각이 몬스터처럼 생겼네. 아니, 그냥 생각이 엉킨 거예요."
- 버튼 → 짧은 자동전투(적 3마리, 체력 낮게). **이 방은 패배할 수 없게** 조정한다.
- 정리 연출: 슬로모션 → 배너 **"정리 완료"** → 정수 회수 → 회복 숫자.
- 반장 "이 정도면 한 방 끝. 정수는 하린 씨 마음 조각이에요. 주워 둬요."

### S4. 방 1 — 새벽 4시의 책상 · 자동전투 + 첫 유물 (2:30~4:30)
- 이동: 복도 석판이 솟아오르고 분대가 걸어 들어간다 (기존 TRAVEL).
- 입장 대사: 마법사 "공책이 여섯 권 펼쳐져 있네요. 다 오늘 거래요."
- **성좌판 첫 공개**: 우측 10칸 중 4칸이 열리며 빛난다. 보관함에 뇌운 조각·잉걸불 2개.
  - 반장 "하린 씨 좋은 기억이에요. 판에 끼우면 알아서 도와줘요."
  - 튜토리얼 손가락: 보관함 → 육각 칸으로 드래그. 두 개 다 끼우면 툴팁에 회색 한 줄 ("첫 합주가 끝났을 때 손끝에 남아 있던 찌릿한 열기.").
- 전투: 「해야 하는데…」 + 「조급함」(파편). 평타 횟수가 쌓여 뇌운 조각이 발동하는 게이지를 한 번 강조한다 ("BANG!" → 이 의뢰에서는 "정리!" 섞기).
- 정리 완료 → 회복 → **칸 +1 (5칸)**.

### S5. 방 2 — 게시판 앞 복도 · 고유 스킬 + 3택1 (4:30~6:30)
- 입장 대사: 건너 "1등 옆에 이름이 있는데… 왜 본인은 2등 칸만 보고 있죠?"
- 새 적 「수군거림」(포자, 원거리): "회장이 저것도 못 해?"
- 첫 고유 스킬 자동 발동 순간 짧게 정지 강조 (마나 바 가득 → 스킬 이름 띠). 반장 "마나 차면 알아서 써요. 신경 끄고 봐요."
- 클리어 → **유물 3택1 첫 등장**: 서리 결정이 확정 포함된 3장. 고른 유물의 기억 한 줄이 크게 한 번 떠오른다:
  > "시험 끝난 날, 친구랑 눈 맞으면서 먹은 아이스크림."
- 칸 +1 (6칸).

### S6. 방 3 — 텅 빈 동아리방 · 궁극기 (6:30~9:00)
- 입장 대사: 힐러 "여긴 먼지만 쌓였어요. …근데 이 기타는 줄이 새 거예요."
- 입장 시 **마법사 궁극기 게이지를 가득 채워 둔다** (튜토리얼 보장).
- 전투 중반 「완벽한 계획표」(결정체, 탱커)가 등장하며 시간 정지 → 튜토리얼: "빛나는 카드를 눌러 보세요" → 조준 화면(어두워짐, 곡선 화살표) → 필드 탭 → **초궁극기 전면 컷인** (마법사).
  - 마법사 (컷인 후) "…시끄러운 건 질색이라서요."
- 클리어 → 3택1 (공허 정수병 포함, "동아리 애들이 몰래 써 준 롤링페이퍼. '회장 고마워'."). 칸 +1 (7칸).

### S7. 갈림길 — "어느 기억부터 볼까요?" (9:00~11:30)
- 출구 2개가 솟고 갈림길 버튼에 방 이름이 붙는다: **축제 무대 뒤** / **혼자 남은 교실**. 첫 런에서는 두 길의 "배우는 것"을 작게 미리 보여 준다.
- 방 클리어 리액션 1줄 (캐릭터 랜덤): 기사 "어디든 좋아. 다 치우면 되지!"
- **4A 축제 무대 뒤** (소켓·인접 문법): 기사 "여긴 공기가 다르네. 따뜻해." → 잉걸불(2번째). 유물을 가리키면 관계 화살표(줌/받음)가 뜨는 걸 처음 보여 준다. "우클릭으로 소켓 회전".
- **4B 혼자 남은 교실** (침식·정화): 반장 "생각이 바닥에 들러붙었어요. 문질러서 지워요." → 클리어 시 침식 칸 확정, 칸 위 글씨 "부족해". 정화(정수 20) → 글씨가 지워지며 칸이 돌아온다. 서리 결정(2번째).
- 고르지 않은 길은 두 번째 방문(재도전·회차)에서 볼 수 있다고 반장이 한 줄로 알려 준다: "저쪽은 다음에 봐요. 한 번에 다 못 치워요."
- 칸 +1 (8칸).

### S8. 방 5 — 왕좌의 방 앞 계단 · 정비 (11:30~13:30)
- 입장 대사: 힐러 "위에서 누가 계속 소리치고 있어요."
- 적 구성은 조금 세게 (보스 예열). 위에서 외침이 상단 메시지 자리에 흘러나온다: "아직 부족해…"
- 클리어 → **별 깃털 확정 지급** (위기 보호막):
  > "초등학생 때 꼴찌로 들어온 운동회 날, 아빠가 '끝까지 뛰었네' 해 준 말."
  - 반장 "이건 맨 윗줄에 둬요. 제일 힘들 때 꺼내 쓰는 기억이에요." (별 깃털 최상단 줄 제약 학습)
- 칸 +1 (9칸). 배치 단계가 평소보다 길다는 걸 알리기: "다음 방은 오래 걸려요. 판 정리 다 했으면 시작해요."

### S9. 방 6 — 왕좌의 방 · 보스 「1등의 왕관」 (13:30~17:00)
- 보스 등장 컷인: 이름 **「1등의 왕관」** · 별명 "2등은 꼴찌랑 똑같아". 상단 보스 바 + 잔상 바, 배경 위험 연출.
- HP 75 / 50 / 25%에 외침 1줄씩: "아직 부족해!" → "쉬면 다 따라잡혀!" → "…날 벗으면, 넌 아무것도 아니잖아."
- 위기 설계: 50% 페이즈에 한 영웅이 HP 50% 아래로 떨어지게 만들어 **별 깃털이 한 번은 반드시 발동**하게 한다. 힐러 궁극기(부활의 기도)도 이때 처음 쓸 만하다.
- 마지막 타격: 터지지 않는다. 슬로모션 → 보스가 줄어들며 **유치원 때 만든 종이 왕관**이 된다.
  - 반장 "이거, 처음 1등 했을 때 받은 거래요. 그때는 그냥… 기뻤대요."
- 칸 +1 → **10칸 완성.** 성좌판 전체가 한 번 빛난다 = "마음 하늘이 밝아졌다".

### S10. 마지막 문 → 엔딩 (17:00~18:30)
- 왕좌 뒤 작은 문. 분대가 멈추고, **하린 초상이 처음 등장**.
  - 하린 "…이 문은 제가 열어도 돼요?"
  - 힐러 "그럼요. 여긴 하린 씨 집인걸요."
- 유저가 문을 직접 탭하지 않는다. 하린이 연다 (원칙 3: 회복의 주체는 의뢰인).
- 엔딩 컷 3장:
  1. 낡은 소파와 기타. 종이 왕관을 소파 위에 살며시 내려놓는다.
  2. 아침 책상. 계획표 맨 아래 연필로 「토요일 — 합주」.
  3. 휴대폰: "이번 주에 떡볶이 먹을래? 할 얘기 있어." → "ㅇㅋㅋ 드디어!!"
- 반장 "다 치운 건 아니에요. 그래도 이제 걸려 넘어지진 않을 거예요."

### S11. 결과 → 상담소 복귀 (18:30~20:00)
- 결과 화면: **「의뢰 완료 — 윤하린」**
  - 정리한 방 7 · 되찾은 기억 n개 · 공허 정수 합계 → **시간의 결정 +N** 으로 환산
  - 하린 엽서 1장 획득 (카드 뒤집기 연출)
- 상담소로 돌아오면 S1에서 그림자였던 메뉴가 하나씩 켜진다:
  1. **엽서 벽**: 첫 엽서가 붙는다. 빈 액자 칸이 여럿 → 수집 목표가 보인다.
  2. **별자리 트리** (영구 성장): 결정으로 노드 하나를 반장이 직접 찍어 보게 한다 ("처음 건 제가 골라 줄게요. 회복량부터.").
  3. **쇼룸** (Tab): 분대 4인 프로필 3줄이 열린다. 잠긴 실루엣 2칸 = 해금 캐릭터 예고.

### S12. 다음 쪽지 — 사이클의 끝이자 시작 (20:00~)
- 문틈에 새 쪽지 (다른 필체). 탭하면 앞 두 줄만 보인다 → "다음 의뢰 받기" 버튼.
- 동시에 하린 의뢰 카드에는 "다시 방문" (안 간 갈림길·남은 기억 수집용) 이 생긴다.
- 반장 "오늘은 여기까지 해도 돼요. 아니면… 한 집 더?" → 여기서 끄면 자연스러운 세션 종료, 계속하면 두 번째 사이클.

## 3. 화면 전환 요약

```
타이틀 ─▶ 상담소 외관(쪽지) ─▶ 상담소 실내(분대 소개) ─▶ 로딩 ─▶ 전투 화면 (방 0~6 반복)
   ─▶ 보스 진정 ─▶ 마지막 문 ─▶ 엔딩 컷 3장 ─▶ 결과 ─▶ 상담소 실내(메뉴 해금) ─▶ 다음 쪽지
```

## 4. 실패 분기 — "오늘 상담은 여기까지"

- 튜토리얼 의뢰는 방 0~3에서 사실상 질 수 없게 하고, 실질 패배 가능 지점은 **방 5·보스**로 둔다.
- 전멸 시: 마지막 아군이 쓰러지는 슬로모션 → 흑백 → 배너 **"오늘 상담은 여기까지"** (현재 "거점 함락") → 컷 1장 (상담소 소파에 늘어진 분대).
  - 반장 "하린 씨, 다음 주에 또 봬요."
- 결과: 엽서 없음, 결정은 도달한 방만큼 지급. 상담소로 복귀 → 트리 해금은 동일하게 일어난다 (실패해도 메타 고리를 한 바퀴 돌게).
- 재도전: 같은 의뢰 카드에 "2회기" 표시. 하린 첫 대사 "…또 와 주셨네요."
  - 2회기부터는 튜토리얼 손가락을 끄고, 방 0을 생략하는 "빠른 입장"을 준다.

## 6. 정해야 할 것

1. **첫 화면**: 타이틀 → 상담소 외관 → 실내까지 다 넣을지, 외관(쪽지) 한 장으로 줄일지. (추천: 첫 실행만 3단, 이후엔 실내 허브로 바로)
2. **첫 런의 실패 가능성**: 튜토리얼 의뢰를 "질 수 없게"(이야기 보상 보장) vs "보스에서 한 번쯤 지게"(로그라이트 루프를 일찍 체험). (추천: 질 수 있되 잘 안 지게 — 별 깃털·힐러 궁극기로 버틸 여지)
3. **허브 톤**: 로비 컨셉 v7 프롬프트의 "밤에만 여는 불법 신경 치료 클리닉 HEAD CASE"는 네러티브 기획서의 "마음 정리 대행 메이드 상담소"보다 어둡다. 간판·설정을 어느 쪽으로 맞출지.
4. **재화 이름**: 결과 화면에 처음 이름이 노출되므로 공허 정수 / 시간의 결정을 상담소 톤으로 바꿀지 이 시점에 정해야 한다.
5. **다시 방문**: 클리어한 의뢰를 다시 들어가는 이유 (안 간 갈림길 기억, 엽서 뒷면, 결정 파밍) 를 둘지.
