원경은 화면을 채우는 불투명 RGB PNG입니다. 나머지 51개는 투명 RGBA PNG이며 스프라이트 바깥에 투명 패딩이 있습니다. 발판의 가려진 타일과 인물의 목·손, 프랍의 잘린 끝은 원화를 참고해 복원했습니다. 그래서 실루엣과 위치는 원화에 맞춘 근사치입니다. 웨이브와 마나 값은 원화에 있던 표기 그대로 이미지에 포함됩니다.

## Godot에서 조립

- 캐릭터 루트는 발 아래에 둡니다. `rigs`의 각 파츠에 `Sprite2D.centered = false`를 적용하고, `offset = -Vector2(pivot_px)`, `position = Vector2(offset_px)`를 넣습니다. 파츠별 `scale`과 `z_index`를 적용한 뒤 전체 크기는 부모 노드에서 조정합니다. 모든 좌표는 픽셀 단위이며 오른쪽과 아래가 양수입니다.
- 머리의 기준점은 목, 무기의 기준점은 손잡이입니다. 기사의 검과 방패에는 각각 기준점이 있습니다. 몬스터 피벗은 몸체 아래쪽, 주변 프랍 피벗은 이미지 중앙입니다.
- `preview_layers`는 재조립에 쓴 그리기 순서와 1672×941 캔버스상의 배치입니다. 각 사각형은 `[x, y, 너비, 높이]`입니다. 아래 트레이의 `slice_x`는 좌우 가장자리를 유지하고 가운데만 늘린 배치입니다.
- 가변 체력바는 `boss_hp_track.png` 위에 `boss_hp_fill.png`를 트랙의 좌상단 기준 `[45, 26]`에 배치하고 채움의 오른쪽을 잘라 표시합니다. `boss_hp_sample.png`는 원화와 비슷한 표시 상태를 한 장으로 쓰는 샘플입니다. 잠금 슬롯과 전술 선택 타일은 각각 같은 PNG를 복제해 사용합니다.
