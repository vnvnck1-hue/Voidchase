# 리팩토링·누수 전수조사 (2026-11-10)

`scripts/` 91개 파일(약 2만 4천 줄)을 영역 5개로 나눠 전부 읽고, 헤드리스 실행으로 확인했다.

## 결론

- **장기 세션 누수 없음.** 새 프로브 `tools/test/LeakProbe.tscn`으로 로비 → 6개 모드 → 로비를 4바퀴 돌렸다. 노드·오브젝트·고아 노드·리소스·설정 메뉴 항목 수는 바퀴마다 **+0**이었고, 메모리 증가는 바퀴당 +0.03MB였다.
  ```
  godot --headless --path . res://tools/test/LeakProbe.tscn -- --rounds=4 --stay=4
  ```
- 테스트가 끝날 때 나오는 `ObjectDB instances leaked` / `resources still in use`는 모두 `AudioStreamPlaybackWAV`다. `quit()` 순간 재생 중이던 효과음이 남은 것으로, 실행 중에 쌓이는 누수가 아니다.
- 실제 버그는 **씬 전환 뒤 엔진 전역 상태가 남는 문제**가 가장 컸다. 그 밖에는 await 뒤 해제된 객체 접근, 새 런에 이전 런 상태가 섞이는 문제를 고쳤다.

## 고친 것

### await 뒤 해제·일시정지 중 진행 (중간)
- 기사 도약, 절대영도, 건너 후퇴: 새 판을 시작한 뒤 해제된 유닛에 `casting = false`를 대입하던 문제 (`vd_skills.gd`)
- 스킬 타이머 5곳과 `_delayed_hit`: 궁극기 연출로 트리가 멈춘 동안에도 착지 피해·탄 명중이 들어가던 문제. `create_timer(t, false)`로 고침
- 히드라 부활 타이머가 해제된 전투에 접근하던 문제
- 연습장 영웅 부활: 메서드에 연결하고 spawn id로 가드
- 유도탄 추적 람다가 유닛을 직접 잡아 `Lambda capture was freed` 오류를 내던 문제: `_homing()` 약한 참조 헬퍼 하나로 통합

### 게임 로직 (중간)
- 유물 투사체: 긴 프레임 하나에 flight와 life를 함께 넘기면 착탄(피해·보호막)을 건너뛰던 문제
- 카운터 유물: 내부 쿨다운에 막혀도 카운트를 0으로 되돌려 발동을 잃던 문제
- 성좌판 보관함: 8칸을 넘겨 담겨 보이지 않던 문제 ("보관함이 가득 찼습니다")
- 누른 채로 전투가 시작된 뒤 놓으면 성좌판이 바뀌던 문제
- 새 런에서 보상 카드·드래그·칸 연출이 남던 문제: `VDRelicHud.reset_run()`
- 새 런에 이전 런의 정수 수거 비행이 정수를 더하던 문제: `VDEssenceDrops` 세대 카운터
- 새 런에 이전 런의 점액 방울이 웅덩이를 만들던 문제: `VDGoo` 세대 카운터
- 영웅을 끄는 중에 전투가 시작되면 전투 중에 놓이던 문제
- 지난 방의 공허 오염 타일이 다음 배치까지 남던 문제
- 둘레가 다 찬 칸에 증원이 겹쳐 내리던 문제, 전멸 뒤에도 증원이 계속 소환되던 문제
- 연구실: UI를 다시 지으면 배속 슬라이더가 1로 돌아가던 문제. 만화 타격이 섬광·타격선 수명보다 먼저 지워지던 문제
- 원화 조립 테스트: 씬을 떠나는 중 `_layout`이 `!is_inside_tree()` 오류를 내던 문제
- `card_ult_flame.gdshader`: 사용자 함수에 `TEXTURE`를 넘겨 셰이더 컴파일 오류가 나던 문제 (매크로로 바꿈)

### 성능
- `UnityParticles2D`: `stop()`했거나 한 번 도는 시스템은 파티클이 다 사라진 뒤 쉰다. 예전에는 빈 시스템이 끝없이 시뮬레이션하고 다시 그렸다
- `UnityParticles2D`: 파티클마다 하던 문자열 비교를 로드 때 한 번으로 캐시
- 더하기 합성 재질을 `VDVfx.add_material()` 하나로 공유 (스파크·광선·반짝이마다 새로 만들던 곳 12곳)
- 초궁극기 컷인 섬광 셰이더를 캐시 (컷인마다 다시 컴파일하던 것)
- 막힌 유닛이 매 물리 틱 길찾기를 돌리던 문제: 이동 주기의 40% 뒤 재시도
- 죽은 유닛의 `_process`: 스테이지 끝까지 남는 시체는 쉬고, 부활하면 다시 켠다
- 웨이브 바: StyleBox 재사용, 실제 시간 시계, 다 가라앉으면 다시 그리지 않음
- 메인 버튼·턴테이블: 숨어 있으면 프레임 처리를 쉼
- 충격파 빈 목록, 정수 tick의 배열 결합, 오디오 `_is_synth`의 배열 할당, 터치 타격 하위 트리 탐색 정리
- CRT·성운·글리치 튜너: 슬라이더를 끄는 동안 틱마다 쓰던 설정 파일을 0.4초 뒤 한 번 쓰고, 떠날 때 남은 것을 쓴다
