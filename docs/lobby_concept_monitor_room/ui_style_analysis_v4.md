# 기존 UI 분석 및 로비 배경 적용

## 확인 자료

- `docs/desert_station_tiles/gameplay/03b_choose_ui_room0.png`: 실제 전투 화면. 하단 캐릭터 카드와 버튼, 상단 대각선 프레임 확인.
- `docs/character_showroom/user_layout_reference.png`: 사용자 작성 기존 쇼룸 구도. 캐릭터 선택 카드와 보라색 배경 확인.
- `docs/캐릭터_쇼룸_UI_결정사항.md`: 두꺼운 라벤더 테두리, 둥근 모서리, 모서리 하이라이트, 진보라색 오프셋 그림자에 관한 결정사항 확인.
- `scripts/void_defense/vd_battle_ui_layout.gd`: 현재 HUD의 대각선 배치와 보라색 팔레트 확인.
- `assets/textures/ui.png`, `docs/void_defense_original/ui_preview.png`: 보조 확인. 최종 스타일 참조는 실제 전투 화면과 사용자 쇼룸 구도를 우선.
- 과거의 다른 로비 원화는 참조하지 않음. 수정 대상은 이 대화에서 생성한 v3.

## 관찰

- 진보라색 바탕과 그림자 위에 라벤더색 둥근 프레임이 놓인다.
- 작은 디테일보다 두꺼운 외곽 형태와 큰 색면으로 읽힌다.
- 모서리의 짧은 밝은 면과 아래쪽 어두운 면이 입체감을 만든다.
- 캐릭터는 검은 윤곽과 단순한 셀 명암을 사용한다. 배경의 선과 대비는 이보다 약해야 한다.
- 보라색 계열을 중심으로 분홍, 청록, 노랑의 국소 강조색을 사용한다.

## v4 적용

- CRT 베젤을 둥글고 두꺼운 라벤더 형태로 바꾸고 모서리에 짧은 하이라이트를 배치.
- 가구와 장비를 큰 실루엣, 진보라 윤곽, 2~3단계의 큰 명암면으로 단순화.
- 벽과 천장의 재질 노이즈, 바닥의 잔질감, 담요의 직물 묘사를 제거.
- 큰 타일과 적은 배선으로 밀도를 낮추고 중앙 집중 구도와 캐릭터 공간을 유지.
- 기억 화면의 청록/분홍과 상담 자리의 작은 따뜻한 조명만 강조.
- UI 자체와 캐릭터를 배경 안에 그리지 않음.

## 산출물과 검토 범위

- `lobby_monitor_room_bg_v4_ui_cartoon.png`
- 내장 image_gen 사용. 최종 생성 프롬프트는 `prompt_v4_ui_cartoon.txt`.
- 생성 결과에서 카툰 형태, 색면, 중앙 여백과 텍스트 부재를 시각적으로 확인.
- 실제 캐릭터와 UI를 합성한 게임 내 가독성은 아직 검증하지 않음. 게임 코드와 실행 배경은 변경하지 않음.
