# 메이드 캐릭터 스파인 파츠 v1

`images/`에 투명 PNG 32장이 있습니다. 머리와 얼굴 15장, 목·의상 4장, 팔 6장, 다리 6장, 하트 1장입니다.

- `parts-preview.png`에서 전체 파츠와 파일명을 확인할 수 있습니다.
- `setup-pose.png`는 각 파츠를 원래 위치에 겹친 기준 포즈입니다. 하트는 별도 이펙트로 켤 수 있게 분리했습니다.
- `layout.json`의 `x`, `y`는 1325 × 1790 원본 캔버스에서 각 PNG의 좌상단 위치입니다. `drawOrder` 숫자가 작을수록 뒤에 배치합니다.
- `pivot`은 원본 캔버스 기준 회전축 후보입니다. `pivotInSprite`는 같은 좌표를 개별 PNG의 좌상단 기준으로 환산한 값입니다. 파일명의 `screen_left`와 `screen_right`는 화면 기준입니다.

가려져 있던 파츠의 뿌리와 관절 겹침부는 추정해 복원했습니다. 포니테일과 일부 의상 경계는 크게 움직이면 복원한 색 경계가 보일 수 있습니다. 홍채를 움직일 때는 흰자 범위 안에서 움직임을 잡아 주세요.
