# 메이드 캐릭터 스파인 파츠 v2

`images/`에 다시 그린 투명 PNG 파츠 32장이 있습니다. 얼굴 바탕과 표정, 머리카락, 목과 의상, 양팔과 양다리, 하트 이펙트를 각각 편집할 수 있습니다.

- `parts-preview.png`는 밝고 어두운 배경에 나란히 놓은 파츠 모음입니다.
- `setup-pose.png`는 원래 배치를 기준으로 맞춘 조립 포즈입니다. `motion-check.png`는 고개와 포니테일을 돌리고, 홍채를 옮기고, 팔꿈치와 무릎을 굽혀 겹침을 확인한 이미지입니다.
- `maid-layered.svg`에는 외곽선, 채색, 명암이 편집 가능한 파츠 레이어로 들어 있습니다. 이미지와 같은 배치에서 파츠를 선택해 수정할 수 있습니다.
- `layout.json`의 `x`, `y`는 1325 × 1790 캔버스에서 PNG의 좌상단 위치입니다. 작은 `drawOrder` 값부터 뒤에서 앞으로 배치합니다. `pivot`은 캔버스 기준 회전축 후보이며, `pivotInSprite`는 같은 점을 PNG의 좌상단 기준으로 환산한 값입니다. 파일명의 좌우는 화면 기준입니다.

홍채 PNG는 눈꺼풀 뒤에 들어갈 부분을 포함합니다. 시선을 움직일 때는 `layout.json`의 `clipping`에 있는 윤곽 좌표로 흰자 범위에 맞춰 가립니다. `maid-layered.svg`에도 같은 영역이 적용되어 있습니다. 파츠에 따라 몸이나 의상에 가려지는 관절의 형태와 일부 명암은 원본을 참고해 다시 그렸습니다.
